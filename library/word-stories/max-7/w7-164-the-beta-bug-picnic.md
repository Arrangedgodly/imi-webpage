# The beta bug picnic

*Format: Story parody*
*Parody target: Software beta excuses basic failures*
*By: IMI Seven Letter Monkey Desk*
*Batch: IMI-W7-004*
*Cast: Coder Glen, User Ula, all fictional monkeys*

## Story

Glen built a lunch app that sent bananas to the wrong desk. Ula got six orders while the other monkeys got none. Glen called it a beta bug. Ula wrote desk names on six cards and handed them to the cook. Lunch reached the right seats. Glen copied that simple list into the app and tested each name once. Ula passed the spare orders along and ate her own share, and Glen stopped using beta as an answer.
