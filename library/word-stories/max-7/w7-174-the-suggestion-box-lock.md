# The suggestion box lock

*Format: Story parody*
*Parody target: Employee feedback systems block feedback*
*By: IMI Seven Letter Monkey Desk*
*Batch: IMI-W7-004*
*Cast: Boss Thistle, Worker Thyme, all fictional monkeys*

## Story

Thistle locked the idea box so no one could steal ideas. Thyme had a note but no key to the slot cover. The monkey worker slid it under the box instead. Thistle found it while dusting and read the request for an open slot. He removed the cover and posted his answer beside it. Thyme put bananas on the shelf as thanks. Thistle ate one and left the box open for the next small useful note.
