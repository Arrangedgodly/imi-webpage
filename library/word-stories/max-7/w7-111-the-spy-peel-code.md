# The spy peel code

*Format: Children's story parody*
*Parody target: Secret messages hidden in food*
*By: IMI Seven Letter Monkey Desk*
*Batch: IMI-W7-003*
*Cast: Agent Ace, Agent Ada, all fictional monkeys*

## Story

Ace wrote a code on a banana peel. Ada ate the fruit, then tossed the peel into the bin. The monkey agents needed the code to open a safe. Ace fetched the peel with his tail and read it upside down. The safe opened to show six clean plates. Ada set the table while Ace copied the code onto paper. They ate more bananas and put every new peel into the compost box.
