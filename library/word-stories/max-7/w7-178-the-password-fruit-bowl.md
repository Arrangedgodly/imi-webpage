# The password fruit bowl

*Format: Story parody*
*Parody target: Security rules that users cannot follow*
*By: IMI Seven Letter Monkey Desk*
*Batch: IMI-W7-004*
*Cast: Clerk Birch, Guard Beryl, all fictional monkeys*

## Story

Beryl made Birch choose a new code each morning. The monkey wrote them on banana peels because he had no spare paper. At lunch he forgot which peel had the current code and could not open his desk. Beryl helped him sort them by color. They chose one strong code and put it in a safe record book. Birch threw the peels into compost and stopped storing office keys beside his lunch.
