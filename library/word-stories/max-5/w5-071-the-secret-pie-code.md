# The secret pie code

*Format: Children's story parody*
*Parody target: Codebreaking detective plot*
*By: IMI Five Letter Monkey Desk*
*Batch: IMI-W5-002*
*Cast: Dot, Gus, all fictional monkeys*

## Story

Gus gets a note that says pie twice. Dot calls it a code. The troop tries each mark on the shed lock. No code works. Dot folds the note and finds jam on its pages. Gus has sent his own wish list. He lost the first note, so he wrote a new one. Dot opens the shed with the key taped to the list.
