# The secret code dinner

*Format: Story parody*
*Parody target: Spy password misunderstanding*
*By: IMI Five Letter Monkey Desk*
*Batch: IMI-W5-005*
*Cast: Pip, Dot, Rex, all fictional monkeys*

## Story

Pip says the code word is soup. The troop goes to the cafe to meet a spy. Each guest asks for soup, so Pip can not tell who is the spy. Dot asks who wants a fork with it. Rex lifts his paw. The real spy knows the next code is fork. Dot gives him a spoon to use. He must eat lunch till they can talk of the plan.
