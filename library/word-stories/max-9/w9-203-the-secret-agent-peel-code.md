# The secret agent peel code

*Format: Story parody*
*Parody target: Spy thriller*
*By: IMI Nine Letter Monkey Desk*
*Batch: IMI-W9-005*
*Cast: Cal, Nia; all fictional monkeys*

## Story

Cal sent a secret code carved in a banana peel. Nia read it beneath an enormous bridge. Rain blurred the marks, making the message say bring chocolate instead of bring locks. Nia arrived at the vault with sweets in her tail. Cal frowned, but the guard opened the door to ask for a taste. Nia shared the box while Cal retrieved the stolen key. They locked the vault again. Cal wrote the next code on dry paper and added chocolate to their kit.
