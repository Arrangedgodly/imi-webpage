# Sorry About the Sponsored Branch

*Format: Song parody*
*Parody target: Influencer apology videos accompanied by ukulele*
*By: IMI Records Encore Monkey Desk*
*Batch: IMI-M1*

*Performance note: Soft ukulele, sincere camera eye contact, one conspicuously placed fruit basket.*

[Verse 1]  
Hey, friends, it's Lolli. I have seen your comments now.  
I said this branch was local, but I had a brand deal somehow.  
The bark was made of plastic, and the leaves were painted green.  
I called it "wild and rooted." That was not exactly clean.  
I filmed beside the river with a ring light and a crew.  
The river was a backdrop. The sponsored branch was new.  
I know I let you down. I want to make this right.  
I turned comments off this morning, then turned them on tonight.  

[Chorus]  
I'm sorry for the branch, I'm sorry for the pose.  
I'm sorry for the discount code below my apology prose.  
I'll listen, learn, and grow, with a pause for you to see.  
Use code LOLLILEAF for ten percent off a tree.  

[Verse 2]  
My monkey cousin held the phone and asked if I was sad.  
I said, "I'm processing the feedback," while unboxing something rad.  
I read the sponsored caption. It said "plant-based delight."  
The caption was approved, though I had slept on it all night.  

[Chorus]  
I'm sorry for the branch, I'm sorry for the pose.  
I'm sorry for the discount code below my apology prose.  
I'll listen, learn, and grow, with a pause for you to see.  
Use code LOLLILEAF for ten percent off a tree.  

[Bridge]  
My cousin says, "Go outside. The real trees don't have links."  
We walk beyond the studio and sit beside the drink.  
A leaf lands on my shoulder. Nobody asks for likes.  
I put my phone away, then check it at the lights.  

[Final Chorus]  
I'm sorry for the branch, I'm sorry for the pose.  
I'm sorry for the discount code below my apology prose.  
I'll listen, learn, and grow, then give the phone a rest.  
No code, no link, no pitch. I will try my very best.  

[Outro]  
The camera light goes dark. The comments still arrive.  
Lolli leaves the plastic branch and lets the real one thrive.
