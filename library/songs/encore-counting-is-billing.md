# Counting Is Billing

*Format: Song parody*
*Parody target: Children's educational counting songs twisted into subscription satire*
*By: IMI Records Encore Monkey Desk*
*Batch: IMI-M1*

*Performance note: Bright classroom piano, hand claps, and a teacher who keeps spotting new fees.*

[Verse 1]  
One little monkey found a music app at school,  
It played a tune about a banana and a rule.  
Two little monkeys joined the lesson on the floor,  
The app said, "Pay to hear the number four."  
Three little monkeys raised a hand to ask why,  
A smiling purple pop-up blinked across the sky.  
The teacher tapped the screen and said, "We'll keep it fun."  
The app said, "Fun is free until you reach number one."  

[Chorus]  
Count one, count two, the basic plan is free.  
Count three, count four, that's premium for a fee.  
Count five, count six, your trial has expired.  
Count seven, count eight, the class is now required.  

[Verse 2]  
Four small monkeys shared a tablet by the sink,  
They tapped the little bell and heard a cash register clink.  
Five small monkeys tried to count without the app,  
But every number vanished in a cheerful loading lap.  
Six small monkeys drew the digits on a board,  
The app declared their chalkwork unauthorized and ignored.  
The teacher shut the tablet, found a box of blocks,  
And built a seven out of crayons, socks, and rocks.  

[Chorus]  
Count one, count two, the basic plan is free.  
Count three, count four, that's premium for a fee.  
Count five, count six, your trial has expired.  
Count seven, count eight, the class is now required.  

[Bridge]  
The monkeys count the bananas, one by one, by hand.  
They count the unpaid invoices stacked beside the stand.  
They count the app's reminders, chirping in a row.  
The teacher counts to ten and says, "It's time to go."  

[Final Chorus]  
Count one, count two, the basic plan is free.  
Count three, count four, that's premium for a fee.  
Count five, count six, the chalk is what we need.  
Count seven, count eight, we learned without a feed.  

[Outro]  
The app asks for a rating. The class holds up a zero.  
They count the lunchroom crackers. Chalk gets voted classroom hero.
