# The Lightkeeper's Radio Check

*Format: Radio play parody*
*Parody target: coastal radio checks, signal etiquette, and a lightkeeper who keeps testing the warning lamp during every message*
*By: IMI Audio Monkey Desk*
*Batch: IMI-M2-AUDIO-010*

CAST
HOST VEX, a macaque
LIGHTKEEPER NARA, a gibbon
RADIO OPERATOR TAVI, a lemur
FISHER OMI, an orangutan

[SFX: WIND AGAINST WINDOWS, RADIO STATIC.]

VEX: We are at the north light station for the nightly radio check. Nara will test the beacon and confirm the harbor channel.

NARA: Beacon ready. Radio ready.

TAVI: Please test one system at a time.

NARA: I can operate both.

[SFX: SWITCH CLACK, ROTATING LAMP HUM.]

OMI (RADIO): I hear a hum, but no voice.

NARA: The beacon is rotating.

TAVI: You switched on the lamp during the radio check.

VEX: The warning light has answered the radio.

NARA: The warning light cannot answer.

TAVI: It is vibrating the microphone stand.

Omi reports from the harbor that the lamp is visible, but he cannot tell whether it is a test or an actual warning. Nara says the beacon has a routine flash pattern.

OMI (RADIO): It flashed twice, paused, then once.

NARA: That is the test pattern.

TAVI: The posted code is one long flash for test, three short flashes for danger.

VEX: We have found two conflicting patterns.

NARA: The old handbook uses the pattern I remember.

TAVI: The new harbor chart uses the posted code.

Omi asks which pattern means he should return to port. Nara reaches for the switch. Tavi stops her until they verify the chart.

[SFX: PAPER UNFOLDS.]

TAVI: The code changed last month.

NARA: No one replaced the handbook.

VEX: The handbook has become an unreliable narrator.

Nara checks the log. The new code was delivered, but the lamp test was never updated. She writes the correct pattern beside the switch, then asks Tavi to read it back before she tests again.

NARA: One long flash means routine test. Three short flashes means danger.

TAVI: Correct. Radio call first, lamp second.

NARA: Harbor station, this is North Light. Routine test to follow.

OMI (RADIO): Received. I am outside the harbor mouth.

[SFX: ONE LONG FLASH, LAMP MOTOR.]

OMI (RADIO): I saw the long flash. I will continue the crossing.

NARA: Confirmed.

VEX: The test has worked.

TAVI: It worked because the message came first.

NARA: I will file a request to replace the handbook.
 
Before signing off, Tavi asks Nara to read the old log aloud. The last entry records a three-short danger flash during a routine test. Omi's boat had turned back unnecessarily that night.

OMI (RADIO): I remember. We tied up at the outer buoy and waited an hour.

NARA: The old code cost you a trip.

OMI: The signal was unclear. I would rather wait than guess.

TAVI: We will add the corrected date to the new board.

VEX: Our report has a real consequence.

Nara writes the date beside the new code and says the old handbook will be archived with a large "superseded" label. Omi confirms the new routine flash before leaving the harbor channel. The log stays current.


TAVI: And remove the old pattern from the wall.

Nara peels off an old instruction card. The paper tears and leaves a strip behind.

[SFX: PAPER RIPS.]

VEX: The old code is resisting removal.

NARA: It is adhesive.

TAVI: Use the scraper in the drawer.

Nara finds the scraper. The card comes off. She writes the new pattern on a clean board and signs it with the date.

OMI (RADIO): Harbor is clear. I am tying up.

VEX: The radio check is complete. No warning was sent, no boat turned around, and the handbook has been retired.

NARA: Tomorrow I will test the lamp.

TAVI: After the radio call.

[SFX: RADIO CLICKS OFF, WIND SOFTENS.]
