# The Pneumatic Tube Under the Library

*Format: Radio play parody*
*Parody target: library systems that automate a simple book return until the book's route becomes a mystery*
*By: IMI Radio Monkey Desk*
*Batch: IMI-M2-AUDIO-012*

Cast: Librarian Dena, a macaque; technician Moss, a gibbon; reader Lio, a lemur; page runner Pavi, a capuchin.

[SFX: LIBRARY ROOM TONE. A BOOK DROPS INTO A METAL RETURN SLOT. A BELL DINGS; AIR WHOOSHES THROUGH A TUBE, THEN STOPS.]

LIO: I returned the book. The screen says it is still checked out.

DENA: What title?

LIO: The Atlas of Little Islands.

MOSS: That goes to the west sorting room.

PAVI: The tube sent it east.

DENA: How do you know?

PAVI: I heard it arrive in the map drawer.

[SFX: DRAWER OPENS. BOOK PAGES FLUTTER.]

LIO: I need to borrow it again. I am using the map for my report.

DENA: We must first check it in.

MOSS: The tube may have registered the drop but not the arrival.

LIO: Isn't that the same book?

DENA: The system tracks locations, not books.

PAVI: I can retrieve it from the map drawer.

[SFX: PAVI OPENS DRAWER. A LOW WHOOSH PULLS THE BOOK BACK INTO THE TUBE.]

PAVI: It left again.

MOSS: The pressure valve is reversed.

DENA: Can we shut the tube down?

MOSS: If we close the main valve, the return slot won't open.

LIO: I can walk the book over.

DENA: The book is moving through the system.

LIO: I am standing still.

[SFX: TUBE WHOOSHES, THEN A METAL CLANG SOUNDS FROM BELOW.]

PAVI: It reached the basement. The old sorter is still connected.

MOSS: That line was retired last year.

DENA: Why is it still on the map?

MOSS: The map is printed. We did not update it.

LIO: The book is going to the wrong room because the tube follows an old map.

DENA: The tube does not read maps.

MOSS: The valve is labeled WEST, but it points east. The pipe crosses under the building.

[SFX: A WRENCH TURNS. AIR HISS FADES. THE TUBE GOES QUIET.]

MOSS: I closed the branch. Pavi, can you get the book from the basement shelf?

PAVI: On my way.

[SFX: FOOTSTEPS DOWN STAIRS, A DOOR OPENS. PAGES RUSTLE. FOOTSTEPS RETURN.]

PAVI: The atlas was sitting on top of the old holiday catalog.

DENA: Scan it here.

[SFX: BARCODE SCANNER BEEPS. A PRINTER SPITS OUT A RECEIPT.]

DENA: Checked in. Lio, you may borrow it again.

LIO: I have not left the desk.

DENA: The system believes you took a long trip.

MOSS: I will relabel the valve and update the floor map.

PAVI: Should we test the return slot?

DENA: One test at a time. We will watch where it goes.

DENA: The loan screen says checked in, but the delivery light still points to the basement. We should explain that to the reader.

MOSS: The status light is controlled by the old branch valve. It changes when the tube arrives, not when a person scans the book.

LIO: So the book is checked in, but the delivery light thinks it is still traveling?

PAVI: The book is on the basement shelf. The light is waiting for the arrival bell.

[SFX: MOSS OPENS A SERVICE PANEL. A SMALL FAN SPINS, THEN CLICKS OFF.]

MOSS: The sensor wire is attached to the retired branch. I can move it to the west receiver.

DENA: Is it safe to test with the atlas?

MOSS: Better to test with a blank return capsule.

[SFX: A METAL CAPSULE IS PLACED IN THE SLOT. AIR WHOOSHES; IT TRAVELS THROUGH THE TUBE AND DINGS AT THE WEST RECEIVER.]

PAVI: The light turned green.

LIO: The book was checked in already. That was only the delivery signal.

DENA: Correct. The sensor tells us where the capsule arrived; the barcode tells us who borrowed the book.

PAVI: We should label the old basement branch as closed.

MOSS: I will remove the old valve handle so no one selects it by accident.

[SFX: SCREWDRIVER TURNS. A METAL HANDLE LIFTS FREE AND IS SET IN A PARTS TRAY.]

LIO: The test paperback can travel the right way.

LIO: I will keep the atlas out of the return tube this time.

[SFX: LIO DROPS A PAPERBACK INTO THE SLOT. AIR WHOOSHES WEST. A BELL DINGS IN THE CORRECT ROOM.]

PAVI: It reached the west receiver. The indicator is green.

MOSS: The line and sensor agree now.

[SFX: LIO CLOSES THE ATLAS. A MAP FOLDS SOFTLY. THE LIBRARY TUBE REMAINS QUIET.]
