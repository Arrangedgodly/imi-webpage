# A Message from the Moon Tree

*Format: Radio play parody*
*Parody target: science fiction radio serial about an automated seed station*
*By: IMI Audio Monkey Desk*
*Batch: IMI-M2-AUDIO-003*

Cast: PILOT EKA, a macaque; TECH ORRO, a capuchin; SHIP VOICE, a calm gibbon; and a distant ground controller.

[SFX: LOW ENGINE HUM, THREE SOFT BEEPS.] 

SHIP VOICE: Seed Station One is approaching the moon tree. Please secure loose tools and do not open the cargo hatch until landing.

EKA: The moon tree is not a tree. It is a research station shaped like one.

ORRO: It has branches for solar panels.

EKA: And roots for landing struts.

ORRO: The seed pod is loose.

EKA: It is attached to the tray.

ORRO: The tray is loose.

[SFX: A SMALL METAL CLINK.] 

EKA: Secure it with the strap.

ORRO: The strap is attached to the tray.

EKA: Then secure the tray to the rack.

ORRO: The rack is attached to the pod.

EKA: The whole station is one attachment.

SHIP VOICE: Landing in ten minutes. Please confirm all seed samples are secured.

EKA: Ground control, this is Eka. We have one loose tray and an unclear attachment diagram.

GROUND: Can you read the serial number on the tray?

ORRO: It says "Do not remove from branch."

EKA: The tray is not on the branch. The branch is a solar panel.

GROUND: The original design was built for a tree.

ORRO: We should set the tray in the root rack once we land.

EKA: We need to keep it still until then.

[ORRO USES A SOFT CLOTH TO WEDGE THE TRAY. THE RATTLE STOPS.] 

SHIP VOICE: Rattle detected. Please secure loose objects.

EKA: The rattle has stopped.

SHIP VOICE: Rattle detected.

ORRO: The voice may be listening to the old sound.

EKA: Ship, confirm current vibration.

SHIP VOICE: Current vibration is within safe range.

EKA: Then update your message.

SHIP VOICE: Seed Station One: the tray is secure. Thank you for the correction.

ORRO: It listened.

EKA: It followed its checklist. We supplied new information.

GROUND: We have a weather update. A dust band is moving across the ridge. Keep the outer panels closed until it passes.

EKA: The seed tray is inside the root rack. We can close the hatch.

ORRO: The hatch is clear now, but a solar branch is still extended.

EKA: Rotate it inward before the dust arrives.

ORRO: The branch controller is using the original tree diagram.

SHIP VOICE: Please place branch one in the upper slot and branch two in the lower slot.

EKA: There is no upper slot. The station is horizontal.

ORRO: If we rotate the frame, the slots will line up.

EKA: The tray is secured. We can tilt the frame a little.

[SFX: METAL FRAME TURNS, A LATCH CLICKS.] 

ORRO: The branch array is home.

SHIP VOICE: Branch array status: flowering.

EKA: That is the old setting. There are no flowers in this mission.

SHIP VOICE: Branch array status: panels secured.

ORRO: It updated again.

GROUND: The dust band is passing. The landing cradle is holding.

EKA: The station has finished one full cycle: approach, land, secure the tray, close the panels.

ORRO: And no seeds have moved.

EKA: One seed has shifted in the dish.

ORRO: It is in the soil now.

EKA: Then it is where the mission intended it to be.

[SFX: DUST RUSTLES ACROSS THE HULL, THEN FADES.]

[SFX: LANDING STRUTS EXTEND. ENGINE HUM SOFTENS.] 

GROUND: The landing site is clear. You can open the hatch.

EKA: The station's outer panel is blocking the hatch.

ORRO: I can rotate the branch array.

EKA: The branches are solar panels. Rotate slowly.

[GEARS TURN. A PANEL CLICKS INTO PLACE.] 

ORRO: Hatch clear.

EKA: The seed tray is steady. We can carry it to the root rack.

ORRO: The root rack has an empty slot shaped for this tray.

EKA: The old design still works, once you know which piece belongs where.

SHIP VOICE: Mission complete. Please return the loose cloth to storage.

ORRO: The cloth is holding the tray.

SHIP VOICE: Mission complete. Please keep the cloth in place.

EKA: Better.

[SFX: SOIL-LIKE GRAIN POURS INTO A METAL TRAY. A SINGLE SEED TAPS THE SURFACE.]
