# The Antique Radio's False Station

*Format: Radio play parody*
*Parody target: restoration broadcasts that mistake electrical hum and dial bleed for a distant station and add invented dialogue*
*By: IMI Radio Monkey Desk*
*Batch: IMI-M2-AUDIO-014*

Cast: Restorer Koto, a lemur; host Mema, a gibbon; technician Yani, a macaque; caller Fela, a capuchin.

[SFX: WORKSHOP. OLD RADIO HUMS. DIAL TURNS THROUGH STATIC.]

MEMA: Koto has found a voice inside this antique radio.

MEMA: The station has a library of old announcer voices. I can add a crackle and a sentence about a lost message.

KOTO: That would make a repair demonstration sound like a recording from the past.

FELA: Could you play the actual unclear syllable before the clean forecast?

YANI: Yes, but we'll state that it is a local broadcast bleeding through between channels.

MEMA: The program wants an old-time filter.

KOTO: Leave the filter off. The speaker cone is already warm and narrow. That is the radio's real sound.

[SFX: DIAL CLICKS BETWEEN STATIONS. STATIC RISES, THEN A CURRENT WEATHER VOICE BLEEDS THROUGH.]

FELA: I hear "forecast at six," not "come."

YANI: Now tune slightly right.

[SFX: KNOB TURNS. STATION CLEARS.]

MEMA: The voice is today's announcer.

KOTO: That's the answer. Keep the original recording, and label the interference as a tuning fault.

KOTO: I haven't. This is mains hum and two stations bleeding together.

FELA: I heard a word, "come."

FELA: The hum makes the speaker shake against the workbench.

YANI: I will place a pad under the case before we test it again.

YANI: The tuning dial is between frequencies. A local station is leaking through.

MEMA: Can we make it sound like a message from the past?

KOTO: It is a current signal. The radio was built in 1940, but that voice isn't from 1940.

[SFX: STATIC. A DISTANT ANNOUNCER SAYS ONE UNCLEAR SYLLABLE.]

FELA: There, again.

YANI: The antenna wire is loose and crossing the power lead.

KOTO: I will unplug the set before touching the wires.

[SFX: PLUG PULLS FROM WALL. HUM STOPS.]

MEMA: We are losing the mystery.

KOTO: We are keeping the radio from humming through the speaker.

YANI: The dial lamp is dark now. I can separate the antenna lead from the power lead.

[SFX: SCREWDRIVER TURNS. WIRE LIFTS FROM CASE.]

FELA: The voice stopped when you unplugged it.

KOTO: So did the hum. A historical recording would still exist on the station archive.

MEMA: The show has a prepared voice actor who can say "come" in an old style.

KOTO: Do not put a new line into the receiver demonstration. We can record narration separately.

YANI: The antenna wire is clear. The speaker cone looks intact.

[SFX: CASE CLOSES. PLUG REINSERTS. RADIO CLICKS ON.]

KOTO: Turn the dial slowly across the marked band.

[SFX: KNOB TURNS. STATIC NARROWS. A CLEAR CURRENT RADIO ANNOUNCER SPEAKS: "WEATHER REPORT AT SIX."]

MEMA: The ghost is a weather report.

FELA: It said "come" because the first word was "forecast."

KOTO: That's what we can prove. The radio picks up the local station when tuned between channels.

YANI: I'll mark the dial positions and replace the brittle antenna sleeve.

MEMA: Could we make the test dramatic with a scratchy voice?

KOTO: Keep the original receiver sound. Add a caption in the spoken description, not a fake voice.

[SFX: PENCIL MARKS DIAL. SMALL SCREW TIGHTENS.]

FELA: I can hear the weather voice clearly now.

YANI: The hum is gone. The antenna is separate from the power lead.

MEMA: The program notes can say "old radio finds a current forecast."

KOTO: Yes. It is not a message from the past.

[SFX: RADIO PLAYS THE SIX O'CLOCK FORECAST. A FILE LABEL PRINTER CLICKS.]

YANI: The label says "local broadcast, tuning test, today's date."

MEMA: That is less spooky.

KOTO: It is more accurate.

[SFX: DIAL TURNS OFF. RADIO CLICKS SILENT.]
