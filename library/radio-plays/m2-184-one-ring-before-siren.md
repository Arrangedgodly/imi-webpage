# One Ring Before the Siren

*Format: Radio play parody*
*Parody target: emergency radio tests that turn routine system checks into suspenseful countdown specials*
*By: IMI Audio Monkey Desk*
*Batch: IMI-M2-AUDIO-007*

CAST
ANNOUNCER KO, a macaque
TECH MIRA, a gorilla
WEATHER VOICE, a recorded local bulletin
PRODUCER PEL, a capuchin
CALLER SANI, a langur

[SFX: SINGLE BELL. STATIC FADES.]

KO: This is Kettle Community Radio with the monthly emergency alert test. This is only a test.

PEL: Can you say that after the drum roll?

MIRA: We have not confirmed the receiver tone.

PEL: The countdown is already in the promo.

[MIRA TURNS THE RECEIVER DIAL. A LOCAL WEATHER BULLETIN BLEEDS INTO THE TEST CHANNEL.]

WEATHER VOICE: Rain after noon, clearing by...

PEL: Is that the mystery signal?

MIRA: It is another station.

[MIRA TURNS THE DIAL BACK. A TEST TONE SOUNDS FROM THE BATTERY SET. KO HOLDS UP A CARD THAT SAYS "THIS IS ONLY A TEST." ]

KO: The card does not make it more suspenseful.

PEL: I can add a countdown.

### Scene One: The Test

[MIRA CHECKS A CONSOLE.]

MIRA: We will send the test tone to the station receiver and the battery radio. If either fails, we stop and troubleshoot.

PEL: Could we make it a live mystery?

KO: There is no mystery. It is a scheduled test.

[PEL STARTS A COUNTDOWN.]

PEL: Ten, nine, eight...

[MIRA PULLS DOWN THE FADER. THE COUNTDOWN STOPS.]

MIRA: The alert tone has not been tested.

PEL: We lost the suspense.

KO: We still have the radio.

### Scene Two: The Wrong Channel

[SFX: A TEST TONE PLAYS THROUGH A SPEAKER, SOFT AND EVEN.]

MIRA: The studio receiver is clear.

KO: Now the battery set.

[STATIC. THE TEST TONE IS DISTORTED.]

PEL: The signal is fading.

MIRA: The antenna is pointed at the ceiling fan.

[THE FAN CLICKS OFF. THE TONE CLEARS.]

KO: The test is working.

PEL: We should call it an unexpected transmission.

SANI: I am listening on the battery set. I heard the tone after I turned the radio away from the fan.

MIRA: Thank you. We will record that placement.

PEL: Can we say a listener solved the signal mystery?

SANI: I moved a radio.

[PEL STARTS THE COUNTDOWN AGAIN. IT ENDS AT ZERO BEFORE MIRA HAS PRESSED THE ALERT BUTTON.]

KO: The tone has not been sent.

PEL: The clock has finished.

MIRA: The clock does not send the tone.

### Scene Three: The Correction

[MIRA PRESSES THE BUTTON. THE TONE PLAYS CLEARLY ON BOTH RECEIVERS.]

[THE TONE STOPS. MIRA CHECKS BOTH SETS. THE BATTERY RADIO HAS A LOOSE COVER THAT RATTLES WHEN IT IS SET DOWN.] 

MIRA: The alert worked. The case needs a latch.

PEL: Could the rattle be the follow-up mystery?

SANI: It is a loose cover.

[SANI PRESSES THE COVER UNTIL IT CLICKS SHUT. THE RADIO STOPS RATTING.] 

KO: Mystery resolved before the next segment.

[MIRA WRITES THE TEST DATE ON THE BATTERY RADIO. PEL ADDS A STAR BESIDE IT.]

MIRA: The star is not an alert.

PEL: Could it be an award sticker?

MIRA: It can be an inventory mark.

KO: The test is logged.

MIRA: The test passed.

KO: The scheduled alert test is complete. No action is required.

PEL: Can we announce a winner?

KO: There is no contest.

SANI: Does the battery set still need new batteries?

MIRA: The indicator is low. We will replace them after the program.

[PEL HOLDS UP A SMALL TROPHY. THE TROPHY SAYS "BEST LIVE MYSTERY." MIRA TURNS IT AROUND; THE BACK READS "PROP RETURN." ]

PEL: The suspense is over.

KO: The information is the point.

### Tag

[SFX: SINGLE BELL.]

MIRA: Test complete.

[THE STATION'S AUTOMATIC SYSTEM PLAYS THE TEST TONE AGAIN, A MINUTE LATE.]

PEL: Encore?

KO: No. That is the duplicate cue.
