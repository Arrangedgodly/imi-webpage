# The Quiz Show Has an Answer for Every Question

*Format: Radio play parody*
*Parody target: quiz broadcasts that protect the host's answer key over common sense*
*By: IMI Radio Monkey Desk*
*Batch: IMI-M2-AUDIO-018*

Cast: Host Vex, an orangutan; contestant Pip, a capuchin; scorekeeper Odo, a gibbon; caller Mara, a macaque; announcer Seli, a lemur.

SFX: Radio quiz studio. Bell dings. Cards shuffle.

SELI: Welcome to One Question More, the quiz show where every answer is final.

VEX: First question: what color is a ripe lemon?

PIP: Yellow.

ODO: The answer key says green.

MARA: I have a lemon in my hand. It is yellow.

VEX: The key was printed in spring, before the lemons ripened.

PIP: Then the key is old.

ODO: I can mark the answer as disputed.

VEX: We cannot change an answer during a live round.

MARA: We can look at the lemon.

SFX: Lemon rolls across the desk and stops against the bell.

PIP: Yellow.

SFX: Bell dings by itself.

VEX: The bell has awarded the point.

ODO: It was bumped by the lemon.

SELI: The audience is calling in.

SELI: We have another card: which animal made the first sound in this studio?

PIP: The fan.

ODO: The answer key says a bird.

MARA: The window was closed when we started.

VEX: Perhaps the bird was in the hallway.

PIP: We heard the fan hum before the first question.

SFX: Fan hum rises in the background.

ODO: The sound is on the opening recording. The scorecard has the wrong answer again.

VEX: The card is written in ink.

MARA: Ink can be corrected. The sound can be replayed.

SFX: Tape clicks back and plays: steady fan hum, then the opening bell.

PIP: No bird.

SELI: The audience can hear the evidence.

VEX: A quiz show should reward memory, not investigation.

MARA: The question asks what made the first sound. Pip remembered it, then we checked.

ODO: I'll cross out bird, write fan, and initial the change.

SFX: Pencil scratches over ink; a correction stamp lands.

VEX: The scorecard now has a visible correction.

VEX: I want the audience to hear the original key before we change it.

MARA: They heard it. We also replayed the recording.

ODO: The correction stays on the card for the next show. We can print a clean copy after we finish.

SELI: The bell rang when the lemon bumped it. I will note that no one answered the last question.

VEX: The bell is supposed to ring when a contestant is right.

PIP: Then the lemon has a point too.

SFX: Lemon rolls gently against the bell again.

VEX: Stop the lemon before it wins the show.

PIP: So can I keep the point?

ODO: Yes. The updated key agrees with what we heard.

VEX: This show cannot change its rulebook on the air.

ODO: We don't need to change the rules. We need to correct a factual answer.

MARA: The rule is that a correct answer earns a point. The key is supposed to help us judge.

PIP: If the key is wrong, the rule can still work.

VEX: Then what is the prize?

SELI: The prize is the brass bell from last season.

SFX: Bell sits on a padded stand.

ODO: Its plaque says "best answer wins." The plaque does not say the host is always right.

VEX: I wrote the plaque.

MARA: You can update that too.

VEX: I will not.

PIP: Then I'll take the point and leave the bell here.

SFX: Card turns over; pencil marks a point.

ODO: Score is now Pip: one. Host: zero.

VEX: Is the game over?

SELI: There are no more questions on today's card.

MARA: Then today's show is over.

MARA: My question: can a quiz show learn from a new answer?

VEX: That is not on the card.

PIP: The answer is yes, if the host lets the scorekeeper update the key.

ODO: I can write a correction in the margin.

VEX: The game needs a winner.

MARA: Pip wins the point, and the key gets a new line.

SFX: Pencil scratches.

TAG

VEX: Final question: did I lose?

ODO: The scorecard says "under review."
