# The Notice Needs One More Line

*Format: Radio play parody*
*Parody target: community radio public-service announcement rehearsals, endless practical disclaimers, and a tree-branch closure that changes before the message airs*
*By: IMI Audio Monkey Desk*
*Batch: IMI-M2-AUDIO-004*

*Cast: Dalla, a langur station announcer; Ro, a macaque safety officer; Fernie, a capuchin sound editor; and Umi, an orangutan caller.*

[SFX: Studio tone, a red recording light clicks on.]

DALLA: This is a community notice for the east branch path. Ro, give us the approved wording.

RO: "The east branch path is closed today for repair. Please use the west path."

FERNIE: That's nine seconds. We have thirty.

DALLA: We can add useful detail. Why is the path closed?

RO: A branch is loose.

DALLA: "A loose branch may fall."

RO: It is not loose now. It is resting against another branch.

FERNIE: Then say "a branch is resting." That sounds calm.

RO: It is resting in a way that may become falling.

[SFX: A woodpecker taps in the distance.]

DALLA: We should mention the woodpecker.

RO: The woodpecker is not part of the closure.

FERNIE: The tapping sounds like a warning.

RO: It is eating.

DALLA: Recording again. "The east branch path is closed while a branch rests against another branch. Please use the west path. The woodpecker is eating."

FERNIE: Thirteen seconds. Good.

[SFX: Phone rings.]

UMI: The west path is muddy. Does the notice say to bring a towel?

RO: No. Bring steady feet.

DALLA: We can add "the west path may be muddy."

RO: It was muddy yesterday. Today it is damp.

FERNIE: We need a moisture disclaimer.

RO: No, we need people to use the path.

UMI: The west path passes the fig tree. Are figs available?

RO: This is not a fruit notice.

DALLA: It could be helpful to tell walkers the figs are not part of the repair.

FERNIE: That adds six seconds.

RO: We cannot announce every thing the notice does not cover.

DALLA: But listeners may assume the closure includes the figs.

RO: The figs are on a different branch.

FERNIE: Then we should say that.

[SFX: Recording light clicks on.]

DALLA: "The east branch path is closed today for repair. The west path is damp. Figs remain available on the separate fig tree. The woodpecker is eating."

RO: The closure has changed. The repair crew removed the loose branch. The path is open.

FERNIE: We just recorded the old message.

DALLA: The closure lasted ten minutes.

RO: The replacement branch is secure. The path is safe.

FERNIE: Is it fully inspected?

RO: Yes.

DALLA: Record the all-clear.

[SFX: Recording light clicks on.]

DALLA: "The east branch path has reopened. The loose branch has been removed. Please use the east path or the west path. The figs remain on their tree."

RO: You don't need to mention the figs.

DALLA: Umi asked.

UMI: I did. I am walking over now.

[SFX: Phone line disconnects; footsteps approach the studio.]

FERNIE: We have fifteen seconds left. Should we say the path is open to everyone?

RO: Monkeys, birds, and careful walkers. No carts until the rail is checked.

DALLA: Add that.

FERNIE: "Open to monkeys, birds, and careful walkers. Carts should wait for the rail check." That's twenty seconds.

RO: The rail check is complete too.

DALLA: Then carts may proceed slowly.

RO: Carts can proceed normally.

FERNIE: We need a third recording.

[SFX: Recording light clicks on.]

DALLA: "The east branch path is open. The loose branch and rail have been checked. Walkers and carts may use either path. Figs are unrelated."

RO: Remove "figs are unrelated."

DALLA: It reassures Umi.

[SFX: Door opens; Umi enters carrying figs.]

UMI: The figs are fine. I came by the west path.

FERNIE: The notice is ready. It says the path is open, the rail is checked, and figs are unrelated.

RO: Use the first two facts. Stop recording before the branch changes again.

[SFX: Recording light clicks off.]

DALLA: The final announcement is short, accurate, and does not describe lunch.

UMI: Can I take one fig?

RO: Yes.

[SFX: A fig is placed on the sound desk.]

DALLA: We have now made lunch part of the notice.

[SFX: Station tone; broadcast fades on a crisp bite.]
