# The School Bell Rings Before the Lesson Plan

*Format: Radio play parody*
*Parody target: educational broadcasts that follow the worksheet after the class has moved on*
*By: IMI Radio Monkey Desk*
*Batch: IMI-M2-AUDIO-017*

Cast: Teacher Mara, a macaque; presenter Vex, an orangutan; pupil Pip, a capuchin; aide Odo, a gibbon; producer Nari, a lemur.

SFX: Schoolroom. Bell rings. Chairs scrape.

VEX: Today's lesson is counting to ten.

PIP: We already counted the class. There are eleven of us.

MARA: The worksheet was copied from last year's group.

NARI: The broadcast card says "ten pupils."

ODO: We can correct the card.

VEX: The audience expects a lesson.

PIP: I can count the chairs.

SFX: Finger taps chair backs.

PIP: One through eleven.

VEX: Start again, slowly.

MARA: The bell rang for recess. The class is leaving.

VEX: We can teach counting during recess.

ODO: The children need coats before they go out.

PIP: Mine is under the table.

SFX: Coat pulls free; a chair tips.

NARI: The microphone is picking up the room, not the worksheet.

VEX: We need a clear educational objective.

MARA: Let's count coats and make sure no one leaves without theirs.

ODO: I have one, two, three...

PIP: That's a lunch bag, not a coat.

VEX: A useful classification exercise.

MARA: Keep the bags on the desk. We are counting students first.

MARA: We need a roll call before the class reaches the yard.

ODO: Eleven names on the list.

PIP: Count us as we pass the door.

SFX: Shoes and paws step one by one.

PIP: One, two, three, four, five, six, seven, eight, nine, ten, eleven.

VEX: The worksheet can use the same number.

NARI: It should say eleven, not ten.

SFX: Pencil erases number; writes 11.

MARA: The lesson objective is met. Now we need to keep the coats separate from the lunch bags.

ODO: I'll put coats on hooks by the door.

PIP: The green coat belongs to Rumi. Mine is the blue one under the table.

SFX: Cloth lifts; chair slides back.

VEX: A second sorting activity.

MARA: A real one. If the coats go home with the wrong students, we will have a new problem.

NARI: I can announce the corrected count before recess ends.

VEX: Use the bell as a transition.

SFX: Bell rings from corridor.

MARA: That bell is for the next class. We should clear the room.

SFX: Footsteps line up.

PIP: Eleven students, eleven coats.

ODO: And one lunch bag.

VEX: The lesson has expanded.

NARI: The class is at the door. It is time to go.

MARA: Pip, check your coat pocket for your permission slip.

PIP: It's here.

VEX: We can close with a quiz.

PIP: What comes after ten?

MARA: Eleven.

SFX: Bell rings again outside.

ODO: That is the return bell.

VEX: We have only been outside for a minute. The test bell has sounded too soon.

VEX: The bell is not on the lesson plan.

ODO: It was rung by the custodian to test the corridor speaker.

NARI: The class thought it meant recess, so the school should update the bell schedule.

MARA: I'll write the actual times on the classroom board.

PIP: Then we won't line up early again.

VEX: Could the correction be today's final question?

MARA: Ask: what number matches the students in this room?

PIP: Eleven.

ODO: And what do we do after the bell?

PIP: Put on our coats and go to the yard.

SFX: Hooks creak as coats lift.

NARI: The clock was set early for testing.

ODO: I'll ask the custodian to reset it before the next recess.

MARA: We can use the time to read the real lesson plan before the next class.
