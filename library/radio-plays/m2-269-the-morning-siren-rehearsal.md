# The Morning Siren Rehearsal

*Format: Radio play parody*
*Parody target: radio civil-alert test broadcasts, formal rehearsal language, and presenters who repeatedly announce that the test is not real*
*By: IMI Audio Monkey Desk*
*Batch: IMI-M2-AUDIO-009*

CAST
ANNOUNCER ONA, a capuchin
TECHNICIAN PEL, a macaque
SAFETY OFFICER DOR, a gibbon
LISTENER VEE, a ring-tailed lemur

[SFX: CONTROL ROOM HUM. BUTTON CLICKS.]

ONA: This is a scheduled rehearsal of the Canopy Morning Siren. This is not an emergency. We will test the tone, then explain that it was a test.

PEL: The tone is ready.

DOR: The warning light should flash before the sound.

ONA: This is a radio broadcast. The listeners cannot see the warning light.

DOR: We still need it for the control room.

[SFX: SWITCH. A SOFT BEEP.]

PEL: That was the printer.

ONA: The printer is not the siren. This is still a rehearsal.

DOR: We should start with the spoken notice.

ONA: Attention listeners. At nine o'clock the siren will sound for twelve seconds. This is a test, not a warning of danger.

VEE: I called to ask if the test will interrupt the gardening program.

ONA: It will last twelve seconds.

VEE: The gardening program is exactly twelve seconds long.

PEL: We can delay the test until it ends.

DOR: The schedule says nine sharp.

ONA: Then the siren will follow the gardening program.

VEE: It is nine now.

[SFX: CONTROL CLOCK TICKS.]

PEL: The signal cable is not connected.

ONA: We have a scheduled test without a connected siren.

DOR: The backup bell is ready.

ONA: Is it the same pitch?

DOR: It is a hand bell.

PEL: It can alert people in the room.

ONA: This is a radio. It will alert people through the microphone.

[SFX: BELL RINGS. MICROPHONE FEEDBACK.]

VEE: That was louder than twelve seconds.

DOR: The bell is not the official signal.

ONA: This remains a rehearsal.

PEL: I have connected the cable.

DOR: Please wait for my signal.

ONA: Should I explain that the test is not real again?

DOR: Once before the tone and once after.

ONA: This is a test. This is not an emergency. The signal will sound for twelve seconds. Do not take action based on the test.

[SFX: SIREN SOUNDS FOR TWELVE SECONDS, THEN STOPS.]

ONA: That was the test. This is not an emergency.

VEE: The gardening program has ended.

PEL: We interrupted it by twelve seconds.

VEE: The host says to remove only the dead branch. That seems especially relevant after a siren.

ONA: We can tell listeners that no branch, building, or garden was harmed during the test.

DOR: No one announced a danger. The alarm was planned and brief.

ONA: We can replay the last segment after the announcement.

DOR: The test was scheduled. We should not edit the recording to hide it.

ONA: We will state that it was interrupted during the scheduled rehearsal.

VEE: The gardener was describing how to prune a branch.

PEL: We can replay that portion.

DOR: Only after the all-clear.

ONA: There is no all-clear for a test.

DOR: Then say the test has ended.

ONA: The test has ended. The gardening program will resume from the point where it was interrupted.

[SFX: RECORDING REWINDS. GARDENER: "CUT JUST ABOVE THE BUD."]

VEE: That sounds useful.

PEL: The siren is off. The cable is disconnected again.

ONA: Why?

PEL: I pulled the plug after the signal.

DOR: Leave it connected for the afternoon test.

ONA: There is another one?

DOR: A rehearsal of the evening test.

ONA: This was a rehearsal of the morning test.

VEE: I will set my radio beside the gardening program.

ONA: Thank you for listening. That was a planned signal test, it has ended, and the station is returning to regular programming.

[SFX: GARDENING THEME. CONTROL ROOM BUTTON BEEPS ONCE.]
