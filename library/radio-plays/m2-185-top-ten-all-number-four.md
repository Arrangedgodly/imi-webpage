# The Top Ten Are All Number Four

*Format: Radio play parody*
*Parody target: countdown radio programs that tease rankings while repeatedly restarting the chart*
*By: IMI Audio Monkey Desk*
*Batch: IMI-M2-AUDIO-007*

CAST
HOST JORI, a macaque
PRODUCER TAV, a capuchin
CALLER EMI, a gibbon
ENGINEER DUK, a gorilla

[SFX: COUNTDOWN THEME, THEN A NEEDLE SCRATCH.]

JORI: Welcome to the Canopy Countdown. We will count the ten most-requested songs this week, starting at number ten.

TAV: Before that, a word from our sponsor.

JORI: We have already said the word.

TAV: This time, the sponsor has a jingle.

[SFX: A THREE-NOTE JINGLE PLAYS.]

### Scene One: The Chart

JORI: At number ten, "Rain on the Roof." Number nine, "The Long Way Home."

DUK: We have only eight songs on the chart.

TAV: The top ten graphic looks better.

JORI: Then why is number four shown six times?

[TAV LOOKS AT THE BOARD. EVERY SLOT SAYS NUMBER FOUR.]

TAV: The printer jammed.

DUK: It printed the same label.

[SFX: PAPER ROLLS OUT, UNWINDING ACROSS THE FLOOR.]

JORI: We will pause the chart until the paper is clear.

TAV: The chart has a long tail.

[DUK PULLS THE LABEL STRIP THROUGH THE SLOT. EACH LABEL READS NUMBER FOUR. HE STACKS THEM; THE TOWER REACHES THE MICROPHONE.] 

DUK: Ten copies of number four.

JORI: That is not a countdown.

[TAV HOLDS UP A FRESH BOARD. THE FIRST THREE NUMBERS ARE MISSING, BUT THE TOP TEN TITLE IS STILL THERE.] 

TAV: We can start at ten again.

DUK: The audience has heard ten already.

### Scene Two: The Request

EMI: I called to ask for "Rain on the Roof." My request was number one last week.

JORI: It is number ten this week.

TAV: We can replay last week's chart before we announce this week's top three.

DUK: That would restart the program.

TAV: It would add suspense.

[THEME MUSIC STARTS AGAIN. JORI TALKS OVER IT.]

JORI: We are not restarting. Number eight is "Morning Branch." Number seven is "Quiet Footsteps." Number six is "The Empty Swing." Number five is "Wind at the Gate."

TAV: And number four...

DUK: We have five songs left.

[TAV COVERS THE BOARD. THE MUSIC CUTS OUT.]

[JORI TURNS THE BOARD AROUND. THE BACK IS A CLEAN SHEET, WITH SPACE FOR THE FIVE SONGS LEFT.]

JORI: We have five songs. We have time for the top three.

TAV: What about the top ten?

JORI: It has taken most of the hour to print them.

JORI: Number four is "The Empty Swing." The printer repeated the label; the song did not repeat.

EMI: Could you play the whole song instead of the ranking tease?

JORI: We have one minute before the news.

### Scene Three: The Last Three

[SFX: THEME MUSIC.]

JORI: Number three, "Small Lantern." Number two, "River Under Ice." Number one, "Rain on the Roof," returning to the top.

TAV: The sponsor wants one more countdown from ten.

DUK: The news starts at the top of the hour.

TAV: We can count quickly.

JORI: We can give the listeners the song.

[DUK FADES IN THE WINNING TRACK. THE PRINTER STARTS AGAIN AND SPITS OUT ANOTHER LABEL: NUMBER FOUR. IT LANDS ON TAV'S HEAD.] 

TAV: I have been ranked.

EMI: Number four?

TAV: Apparently.

[THE SONG CONTINUES. THE HOST DOES NOT SPEAK OVER IT.]

[TAV REACHES FOR THE MICROPHONE TO ANNOUNCE ANOTHER RANKING. DUK POINTS TO THE SONG'S PLAYBACK LIGHT. TAV LOWERS HIS HAND AND LISTENS.] 

JORI: We can let the winner play.

[THE PRINTER BEEPS. DUK REMOVES THE FINAL LABEL: NUMBER FOUR.]

DUK: We have one correct label.

JORI: Save it for next week.

### Tag

[SFX: SONG FADES OUT. A SINGLE TONE MARKS THE NEWS.]

JORI: That was number one.

DUK: The printer says number four.

JORI: The printer is not on the chart.
