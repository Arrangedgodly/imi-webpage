# The Mystery of the Missing Last Page

*Format: Film parody*
*Parody target: whodunit mysteries that hide a simple production mistake beneath a crowded suspect board and a grand parlor reveal*
*By: IMI Pictures Monkey Desk*
*Batch: IMI-M2-FILMS-016*

Logline: A monkey detective gathers every cast member to solve a missing final page, then discovers the mystery is caused by the printer's double-sided setting.

Cast: Detective Luma, a macaque; editor Pavi, a gibbon; actor Neri, a capuchin; stage manager Toma, a lemur; printer technician Odo, an orangutan.

SCENE 1 - INT. REHEARSAL HALL - MORNING

Luma studies a script with its final page missing. A board behind her lists suspects: editor, actor, stage manager, printer.

LUMA: The last page vanished after rehearsal.

NERI: I was the last one to hold the script.

TOMA: You returned it to the table.

PAVI: I edited the scene, but I did not print it.

Luma circles each name and adds a string between them.

SCENE 2 - INT. COSTUME ROOM - LATER

Luma searches the costume rack. She finds a folded page in a coat pocket. It is a page from the previous draft, with a different ending.

LUMA: The actor had access to the script.

NERI: I put the coat away after rehearsal. I did not take the page.

Toma checks the prop log. The coat was used in a scene change, and the script was on the table nearby.

TOMA: The page could have fallen into the pocket.

LUMA: Or been planted.

SCENE 2A - INT. REHEARSAL HALL - CONTINUOUS

Luma interviews Pavi at the editing table. Three versions of the script are stacked beside the printer.

LUMA: Which version did you print?

PAVI: The one with the blue cover.

LUMA: This copy has a green cover.

PAVI: The printer was out of blue paper. I used the green cover sheet.

Neri opens the script. Page numbers jump from eight to ten. Toma checks the floor and finds page nine under the table leg.

TOMA: The missing number was under a chair.

LUMA: We have found page nine. We still need the last page.

Neri reads the recovered page. It ends with a direction to turn the call sheet over.

NERI: The script itself points to the clue.

Pavi reaches for the call sheet, but Luma stops him.

LUMA: Wait. If the page is on the back, we need the printer log before we draw a conclusion.

Toma checks the paper tray and sees the duplex icon lit on the display. The icon flashes, then clears after another sheet feeds through.

TOMA: The machine has been printing on both sides all morning.

Luma removes the strings from the suspect board but keeps the names pinned until the page is verified.

SCENE 3 - INT. PRINTER ROOM - AFTERNOON

Odo opens the printer tray. There are several blank sheets and one page printed on both sides. One side contains the end of the scene; the other contains a shopping list.

ODO: The printer was set to duplex. It printed the final page on the back of the call sheet.

LUMA: The call sheet is not here.

Odo points to a clipboard in the rehearsal hall. The missing page is on the back.

SCENE 4 - INT. REHEARSAL HALL - CONTINUOUS

Luma gathers the suspects for a parlor-room reveal. Neri, Pavi and Toma sit in a semicircle. Odo holds the call sheet. Luma describes the printer, the coat pocket and the missing page.

LUMA: The page was not stolen. It was printed on the reverse of the call sheet, then folded into the costume by accident.

NERI: I put the sheet in the coat pocket because I was carrying both.

PAVI: I used the printer's default setting.

TOMA: The coat rack did not make a move.

Luma untangles the strings on her board. They loop around the marker and pull it off the wall.

SCENE 5 - INT. REHEARSAL HALL - MOMENTS LATER

Odo changes the printer setting to single-sided. Pavi prints a new script. The final page is present and correctly numbered. Neri rehearses the final line. Toma checks the call sheet and costume pocket before closing the room.

LUMA: The mystery has been solved. The culprit was duplex printing.

NERI: The culprit was me putting the sheet in the coat.

PAVI: The cause was the printer setting. The chain of events had three parts.

Luma pins the complete script to the board. She removes the suspect names and replaces them with a note: CHECK BOTH SIDES.

Odo runs one test page. It prints on a single side. The second side remains blank.

FINAL IMAGE: The full script rests on the rehearsal table, with the last page visible and the suspect board repurposed as a printer instruction sign, beside the spare cable.
