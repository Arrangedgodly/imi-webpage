# The Undercover Librarian

*Format: Film parody*
*Parody target: spy thrillers that treat whispering, code names and disguises as intelligence even when a simple question would solve the problem*
*By: IMI Pictures Monkey Desk*
*Batch: IMI-M2-FILMS-016*

Logline: A monkey agent infiltrates a library to recover a classified folder, only to discover it was placed in the returns bin with a clear label.

Cast: Agent Siva, a macaque; librarian Omi, a gibbon; handler Reka, a capuchin; security guard Pavo, a lemur; student Tika, an orangutan.

SCENE 1 - INT. PUBLIC LIBRARY - MORNING

Siva enters wearing a fake mustache and carrying an oversized book. She scans the quiet room. A folder marked CLASSIFIED is visible on the returns cart.

SIVA (into earpiece): The target is in plain sight.

REKA (V.O.): Confirm no witnesses.

Siva looks around. Every table is occupied by readers.

SIVA: The building is full of witnesses.

REKA: Proceed with discretion.

Siva whispers to Omi at the desk.

SIVA: I need the folder.

OMI: You can pick it up from the returns cart.

Siva pretends not to hear and walks toward the stacks.

SCENE 2 - INT. LIBRARY STACKS - MOMENTS LATER

Siva examines a book on gardening. A fake mustache begins to peel off. She presses it back while trying to listen to the earpiece.

REKA: Have you located the code?

SIVA: There is no code. The folder has a label.

REKA: Do not say that aloud.

Tika, a student, reaches around Siva for a book.

TIKA: Your mustache is on the floor.

Siva picks it up. The security guard Pavo approaches.

PAVO: Are you looking for something?

SIVA: A book.

PAVO: Which one?

SIVA: The classified folder.

SCENE 3 - INT. LIBRARY DESK - CONTINUOUS

Omi takes the folder from the return cart. It contains a library inventory for a city archive. The front page says RETURN TO ARCHIVES BY NOON.

OMI: This was misdelivered. It belongs across the street.

SIVA: My mission is to retrieve it secretly.

OMI: I can sign it out to you if you have a card.

Siva produces a spy badge. Omi examines it.

OMI: This is not a library card.

Siva flips the badge. The back reads TEMPORARY ACCESS, FILM UNIT.

PAVO: Are you filming?

REKA (V.O.): Agent, withdraw. The operation has been compromised.

SIVA: The operation is a return errand.

SCENE 3A - INT. LIBRARY REFERENCE AREA - MOMENTS LATER

Siva takes the folder to a table. She opens it just enough to see a list of boxes and shelf numbers. Omi quietly brings a reference guide.

OMI: The archive inventory lists the boxes that need relabeling.

SIVA: The folder contains all the codes.

OMI: They are shelf codes. A is upstairs, B is downstairs.

Siva studies the page. Her earpiece crackles.

REKA: If the file is encrypted, do not read it aloud.

SIVA: I am reading the shelf number. It says B-14.

A nearby printer starts. Siva slides under the table, expecting an alarm. Omi picks up the printed receipt.

OMI: That is the checkout slip. The printer has not printed anything classified.

Tika arrives with a stack of books. One book is tagged B-14. It belongs to the library's local history collection.

TIKA: I found the matching shelf. The folder's return address is on the first page.

Siva turns the page. The address is stamped in large letters.

SIVA: We could have skipped the code-breaking.

OMI: We could have asked at the desk.

SCENE 4 - EXT. LIBRARY STEPS - DAY

Omi gives the folder to Siva in a plain envelope. Pavo watches as Siva crosses the street to the archive. She delivers it to a clerk, who signs the receipt.

SIVA: The target is secured.

CLERK: Thank you for returning the inventory.

Siva reports to Reka by phone.

REKA: Did you retrieve the secret file?

SIVA: I delivered a misdirected inventory to its owner.

REKA: Was the code intact?

SIVA: There was no code.

SCENE 5 - INT. LIBRARY - AFTERNOON

Siva returns without the mustache. Omi helps her sign up for a library card. Pavo checks the fake badge and hands it back to her.

PAVO: You can use it in the film unit, not to access the stacks after hours.

SIVA: Understood.

Tika asks for the gardening book. Siva finds it and hands it over. The book contains a bookmark with the phrase CLASSIFIED PLANTS. Tika points to the chapter on secret gardens.

TIKA: This is the code name for a page section.

Siva smiles and gives the book to Omi for checkout. Reka calls again, asking for the mission report. Siva writes: "Folder returned. No spycraft required."

FINAL IMAGE: Siva's new library card sits beside the returned receipt as the fake mustache rests in the lost-and-found tray.
