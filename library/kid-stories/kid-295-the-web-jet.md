# The web jet

*Format: Children's story parody*
*Parody target: A space pilot mistakes his own toy tether for an invisible obstacle*
*By: IMI Kids Monkey Desk B*
*Batch: IMI-KIDS-B-002*
*Cast: Pip, Bo, monkeys*

## Story

Bo had a toy jet. Pip put it on a web. Bo got in. The jet got as far as a log. "Why am I by the log?" Pip had the web in his paw. He let it go. The jet got by the log. Bo was off. Pip had to run to get it.
