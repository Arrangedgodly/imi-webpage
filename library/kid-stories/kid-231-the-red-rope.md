# The red rope

*Format: Children's story parody*
*Parody target: Hero gadget becomes a jump rope*
*By: IMI Kids Monkey Desk B*
*Batch: IMI-KIDS-B-001*
*Cast: Kit, Gus, monkeys*

## Story

Kit has a red web for Gus in a pit. Gus got it. Kit did tug. Gus got up a bit and hit mud. Kit did tie it to an oak. Gus got out. He got one end of the web up. Kit did hop in it. The web was now a toy for all.
