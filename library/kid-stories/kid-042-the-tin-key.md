# The Tin Key

*Format: Children's story parody*
*Parody target: Secret palace vaults, with the treasure eaten at once*
*By: IMI Kids Monkey Desk A*
*Batch: IMI-KIDS-A-001*
*Cast: Pip, Kit, monkeys*

## Story

Pip got a key. Kit saw it was tin. "A den may get a gem!" Pip did try a box. No fit. He did try a jar. It did fit. Kit saw a nut. Pip ate it. Kit got one too. Now the gem was in a gut. Pip put the key in the jar. No one had to dig for it.
