# The loud hush

*Format: Children's story parody*
*Parody target: Stealth gadget announces silence*
*By: IMI Kids Monkey Desk B*
*Batch: IMI-KIDS-B-001*
*Cast: Gus, Fay, Max, monkeys*

## Story

Max has a box to cut all din. Fay put it in her bag. The box did cry, "Shh!" Gus got up. The box did cry a lot. Fay set it by a sea and ran. Gus bid it end the din. It did not end it. Max got a new box. Fay did ask for no din at all.
