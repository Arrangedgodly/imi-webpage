# The code cup

*Format: Children's story parody*
*Parody target: Spy password gets mistaken for a food order*
*By: IMI Kids Monkey Desk B*
*Batch: IMI-KIDS-B-001*
*Cast: Gus, Max, monkeys*

## Story

Max met Gus at a tea hut. "The red hen has a tan hat," Max did say. Gus got him a red cup and a tan lid. "I ask for the key!" Max did cry. Gus put a key in the cup. Max got it. He had to pay for tea too.
