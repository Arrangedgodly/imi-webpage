# The Hay Prize

*Format: Children's story parody*
*Parody target: Royal horse races, with the winning horse eating the crown*
*By: IMI Kids Monkey Desk A*
*Batch: IMI-KIDS-A-002*
*Cast: Max and Dot, monkeys*

## Story

Max had a nag for a run. It did not run. Dot set an oat by its lip. It ate. Dot set an oat by the far end of a rug. It ran to it. Max won a cap of hay. The nag ate it too. Max had no cap, but the nag won tea.
