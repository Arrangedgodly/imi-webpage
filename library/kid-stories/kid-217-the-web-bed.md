# The web bed

*Format: Children's story parody*
*Parody target: Hero rescue gear turns into a hammock*
*By: IMI Kids Monkey Desk B*
*Batch: IMI-KIDS-B-001*
*Cast: Kit, Max, monkeys*

## Story

Max was up in an oak. Kit set a web to get him out. Max got in it and lay low. Kit did tug. Max did not get up. "Are you ill?" "No. It is a bed." Kit got in too. By six the two had a nap. No one got out.
