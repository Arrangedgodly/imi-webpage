# The Box Map

*Format: Children's story parody*
*Parody target: Treasure-map expeditions, with the guide sitting on the prize*
*By: IMI Kids Monkey Desk A*
*Batch: IMI-KIDS-A-001*
*Cast: Max, Pip, monkeys*

## Story

Max let Pip use his map to a gem. Pip dug by an oak. He dug by a hut. Max sat on a box to see. Pip did ask how to get in it. Max got up. It had a nut. Pip got the nut. Max put an X on his box.
