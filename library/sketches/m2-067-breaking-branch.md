# Breaking Branch

*Format: Comedy sketch*
*Parody target: local television news and live disaster coverage*
*By: IMI Sketch Monkey Desk*
*Batch: IMI-M2-SKETCHES-003*

Cast: ANCHOR VEE, a macaque; REPORTER KEM, a gibbon; CAMERAPERSON NELL, a capuchin; and GROUNDSKEEPER ODO, a baboon.

[News studio. A giant map shows one branch across a footpath. Red graphics flash.]

VEE: We interrupt our regular program with breaking news. A branch has fallen beside the east path.

KEM: I am on the path. It is a branch about as long as a bench.

VEE: Is the whole forest affected?

KEM: No. The other trees are standing.

NELL: The camera is shaking.

KEM: The camera operator is walking around the branch.

VEE: We have lost the shot. Stay with us.

[Back in the studio, Vee points at a map with a red circle around the entire forest.]

VEE: The branch has been described as "large." What does that mean?

ODO, REMOTE: It is too large for one person to lift.

VEE: Could it be a sign of a wider crisis?

ODO: It is a sign that a branch fell.

KEM: The path is closed for now. The grounds crew is coming with a cart.

VEE: Is there an alternate route?

ODO: The north path is open. It is marked with yellow cones.

VEE: We have a viewer question. Should residents avoid every tree?

KEM: No. Walk around the closed path. Don't climb over the branch.

[The studio graphic flashes: "FOREST IN LOCKDOWN."]

VEE: That is not our headline.

NELL: It is the graphic the producer sent.

ODO: The headline should be "One Path Closed."

[The graphic shrinks to a small red line beside the east path.]

VEE: A new update. The crew has reached the branch.

[SFX: CART ROLLS, SAW STARTS, THEN STOPS.]

KEM: The branch is now in sections.

VEE: Has the crisis passed?

ODO: The branch is on the cart.

NELL: The north path is still open.

VEE: And what about the forest?

ODO: It is still a forest.

[The crew removes the cones. The camera zooms on a small leaf left behind.]

VEE: We will monitor the leaf.

KEM: Please don't.

[The news music swells. Odo takes the leaf to the compost bin.]


VEE: We have a new report from the studio. The red circle now marks the branch's exact location.

KEM: The branch is already on the cart.

VEE: The graphic has not caught up.

NELL: The camera is still pointed at the empty path.

ODO: The crew cleared it ten minutes ago.

VEE: Is there any other hazard?

ODO: There is a wet patch from the rain.

KEM: It is drying.

VEE: Should we issue an alert?

ODO: No.

[The studio screen flashes: "WET PATCH WATCH."]

VEE: We are canceling the alert.

NELL: The cancel graphic says "CANCELLED CRISIS."

ODO: Just put up the open-path sign.

[They replace the screen with a plain map showing the east path open and the north path clear.]

VEE: Thank you for staying with us through this developing branch story.

KEM: It has finished developing.

[The news theme begins. Vee points to the map. The map is upside down.]

[BLACKOUT.]
