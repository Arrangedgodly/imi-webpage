# The Library Book Returns Itself

*Format: Comedy sketch*
*Parody target: procedural mysteries and self-checkout kiosks that treat an early book return as a suspicious event*
*By: IMI Sketch Monkey Desk*
*Batch: IMI-M2-SKETCHES-013*

Cast: LIBRARIAN, a baboon; READER, a macaque; TECHNICIAN, an orangutan; DETECTIVE, a gibbon; BOOK, a capuchin.

[A library returns desk. A book slides into the return slot by itself. The librarian rings a small bell.]

DETECTIVE: Nobody touch the evidence.

LIBRARIAN: It is a book return.

DETECTIVE: It returned before opening.

TECHNICIAN: The automatic conveyor is on a timer.

[The detective puts on gloves and leans over the slot. The book speaks from inside the bin.] 

BOOK: I am due today.

READER: I placed it in the slot last night.

DETECTIVE: Why did it arrive now?

READER: Because the slot was closed when I came back.

[The technician checks the conveyor. A small rollers belt moves the book toward the sorting cart, then stops at a divider.] 

TECHNICIAN: It is not moving now. The divider is stuck.

DETECTIVE: The suspect has stopped at the scene.

LIBRARIAN: The suspect is a divider.

[The librarian lifts the divider after the technician switches off the conveyor. The book moves into the correct cart. The detective follows it with a notebook.] 

DETECTIVE: We need a motive.

BOOK: I have no overdue fees. I was read on time.

READER: I finished the last chapter on the bus.

DETECTIVE: A public alibi.

[The technician checks the due date and scans the book. The return is confirmed. The detective asks the librarian to keep the bin sealed until the investigation is over.] 

LIBRARIAN: The investigation is over.

DETECTIVE: What about the next book?

[Another book drops into the slot. The detective flinches. The librarian checks the clock; the library has opened.] 

LIBRARIAN: That one is returning during business hours.

DETECTIVE: We will classify it as routine.

BOOK: I would like a quieter cart.

[The reader takes a new book from the shelf. The technician resets the conveyor timer, now with the divider clear.] 

[The detective asks the technician to explain the timer. The technician shows a small dial set to the library's opening time; the conveyor begins only when the doors unlock.]

TECHNICIAN: The book entered the bin last night. The belt held it until opening.

DETECTIVE: So it did not arrive on its own.

LIBRARIAN: It returned through the slot. The timer moved it to the cart.

BOOK: I was in the return bin before the library opened. I was scanned after it opened.

[The detective compares the date stamp with the clock. The return is on time. The clerk stamps the receipt and hands it to the reader.]

DETECTIVE: The timeline is clear.

READER: May I borrow another one?

LIBRARIAN: Yes. The mystery shelf is in the next aisle.

[The detective takes a mystery book, then turns it around to check whether it has already been returned.]

DETECTIVE: I will read this one at home.

FINAL IMAGE: The returned book rests in the right cart while the detective labels the case "ON TIME."
