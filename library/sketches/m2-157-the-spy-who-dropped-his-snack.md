# The Spy Who Dropped His Snack

*Format: Comedy sketch*
*Parody target: spy thrillers with coded exchanges and dramatic disguises applied to a troop sharing a picnic*
*By: IMI Sketch Monkey Desk*
*Batch: IMI-M2-SKETCHES-005*

Cast: Agent Nira, a macaque; handler Odo, a baboon; lookout Venn, a gibbon; and courier Piri, a capuchin.

[A PICNIC TABLE IN A PARK. ODO SLIDES A BANANA UNDER A NAPKIN.]

ODO: The package is in place.

NIRA: What is the code?

ODO: "The sun is warm."

[VENN LOOKS AT THE SKY.]

VENN: It is cloudy.

ODO: Then the code is wrong.

[PIRI ARRIVES, WEARING SUNGLASSES.]

PIRI: I have the message.

NIRA: Where is it?

[PIRI HOLDS UP A LEAF WITH A MAP DRAWN ON IT.]

NIRA: This map leads to the picnic basket.

PIRI: The basket is the drop point.

[ODO OPENS THE BASKET. A MONKEY IS INSIDE, EATING FRUIT.]

ODO: We have a compromised location.

[THE MONKEY TAKES THE LEAF MAP.]

NIRA: The courier has lost the message.

PIRI: The message was never secret.

[THE MONKEY CLIMBS A TREE WITH THE MAP. VENN USES BINOCULARS.]

VENN: The target is moving east.

NIRA: That is a branch.

ODO: It is an elevated escape route.

[THE MONKEY DROPS THE MAP. NIRA CATCHES IT.]

NIRA: We have the intelligence.

[THE MAP IS SMEARED WITH FRUIT JUICE.]

PIRI: It now has a stain.

NIRA: The stain marks the drop point.

ODO: Which is the basket.

[THEY ALL LOOK AT THE BASKET.]

VENN: Should we secure it?

[THE MONKEY RETURNS AND TAKES THE BANANA.]

NIRA: The package is gone.

ODO: The operation is over.

PIRI: It was lunch.

[NIRA STUDIES THE MAP.]

NIRA: The stain points to the far side of the clearing.

PIRI: It is fruit juice.

NIRA: All intelligence has a source.

ODO: We should move before the target leaves.

[THE GROUP SNEAKS TOWARD THE BASKET. THE MONKEY WATCHES FROM THE BRANCH.]

VENN: The target has spotted us.

[THE MONKEY DROPS THE BANANA PEEL. ODO SLIPS, CATCHES HIMSELF ON THE TABLE.]

ODO: We have triggered a trap.

PIRI: It is a peel.

NIRA: Then the trap is natural.

[THEY PICK UP THE PEEL AND PLACE IT IN A BIN.]

VENN: The path is secure.

NIRA: We need a code word for the return.

ODO: "The sun is warm."

[THE CLOUDS PART. EVERYONE LOOKS UP.]

PIRI: The code is now accurate.

[THE MONKEY CLIMBS DOWN AND WALKS PAST THEM WITH A SECOND BANANA.]

NIRA: We have eyes on the target.

NIRA: We have shared the package.

VENN: The mission has been declassified.

[THE GROUP SHARES THE BANANA UNDER THE PICNIC TABLE.]

ODO: The operation has become a meal.

NIRA: That is a better ending.

VENN: I will file the short report.

[THE MONKEY OFFERS HALF THE BANANA TO NIRA. SHE ACCEPTS.]

NIRA: We have made contact.

VENN: Should I write a report?

ODO: Keep it brief.

[VENN WRITES: "SNACK SHARED. MISSION COMPLETE." THE MONKEY TAKES THE PEN.]
