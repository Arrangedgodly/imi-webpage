# The Escape Room Host Cannot Find the Exit

*Format: Comedy sketch*
*Parody target: puzzle-room hosting and guides who become trapped in the atmosphere they created*
*By: IMI Sketch Monkey Desk*
*Batch: IMI-M2-SKETCHES-015*

Cast: HOST, a gibbon; TEAM CAPTAIN, a macaque; PLAYER TWO, a baboon; TECH, an orangutan; CLEANER, a capuchin.

[A puzzle room dressed as a library. A digital clock shows 45:00. The host gives a dramatic introduction.]

HOST: Find the key and escape before time runs out.

TEAM CAPTAIN: Where is the key?

HOST: I cannot tell you.

[The host closes the door. A second later, a panel slides shut behind them too.]

PLAYER TWO: The host is still inside.

HOST: That is part of the atmosphere.

ACT ONE

[The team searches the shelves. The host tries the door. It will not open. A sign says EXIT. The host pulls a book, revealing a clue. The team pulls the other books, creating a pile.]

TEAM CAPTAIN: We found a cipher.

HOST: I was going to mention the cipher.

PLAYER TWO: You are playing too.

[The host asks the tech over the intercom to release the door. The tech asks for the code. The host looks around and sees the keypad is hidden behind a fake dictionary.]

HOST: The code is in the room.

TECH: Is it in the room you are in?

[The players solve a riddle and open a drawer. It contains a plastic key and a note: "Do not use this key on the front door." The host tries it on a panel marked STAFF EXIT. The panel is actually the laundry cabinet, dressed as a false door. The key fits that cabinet.]

HOST: That is a red herring.

TEAM CAPTAIN: It is a key to a cabinet.

[The cleaner arrives in the corridor and collects towels. She looks through the small window in the single front door, where the host is still in costume.]

CLEANER: Are you the cleaner?

HOST: I am the host.

CLEANER: Then why are you still in the room?

[The team solves the last clue and finds the front-door key inside the fake dictionary. The captain uses it; the front door opens once. The host is standing behind the players, still inside.]

PLAYER TWO: The game is over. You have to come out too.

HOST: I have a shift to finish.

TEAM CAPTAIN: Finish it from the lobby.

[The host steps through the already-open doorway with the team. The host hands the plastic cabinet key to the cleaner, who takes it and hangs it on its labeled hook.]

ACT TWO

[In the lobby, the host turns his briefing card around. The back contains the same cipher that trapped him, printed upside down. He asks the captain to hold it level while he takes a pencil from the welcome desk.]

HOST: The room has followed me out.

TEAM CAPTAIN: The puzzle is in the lobby now.

[The host rotates the card, solves the last clue, and writes the answer on the completion card. The cleaner points to the sign above the welcome desk: STAFF ONLY. The host moves his chair one step away from the sign.]

[The group is together in the corridor. Through the window, the stopped timer shows 00:03, frozen when the captain opened the door. The players receive a completion card, and the host signs it as both game master and last person out.]

TEAM CAPTAIN: Was that planned?

HOST: It is now.

FINAL IMAGE: The host hands the next group the briefing card, then checks the exit latch from the outside.
