# Escape Room for One

*Format: Comedy sketch*
*Parody target: escape-room challenge shows and timed puzzle spectacles*
*By: IMI Sketch Monkey Desk*
*Batch: IMI-M2-SKETCHES-003*

Cast: HOST MIRA, a macaque; PLAYER KETT, a gibbon; PUZZLE DESIGNER VEX, a capuchin; and a VOICE FROM THE SPEAKERS.

[A room contains a locked door, three drawers, and a painted mural of a tree. A clock counts down from ten minutes.]

MIRA: Kett has ten minutes to escape the room. The clues are hidden in the mural, the drawers, and the room's one real branch.

KETT: Is the branch part of the puzzle?

VEX: We can't tell you.

KETT: It looks sturdy.

MIRA: Please don't climb it until you solve the clue.

[The speaker crackles.]

VOICE: Find the first number where the painted leaves meet the painted roots.

[Kett studies the mural, then turns it upside down.]

VEX: That's not how the mural is displayed.

KETT: The roots point to four.

[He opens drawer four. It contains a key ring with no keys.]

MIRA: A false lead.

KETT: Or a clue about missing keys.

VEX: It is a key ring.

[Kett reaches into the next drawer and finds a real key under a felt leaf.]

MIRA: The clock is at six minutes.

KETT: The lock is on the door, but the keyhole is too low.

[He crouches. The key fits. The door does not open.]

VEX: You need the second clue.

[Kett looks at the branch. A tag hangs from it: LIFT HERE.]

MIRA: Is the branch part of the puzzle?

VEX: It is a prop.

KETT: The tag says lift.

[He lifts the branch slightly. A latch clicks. The door opens.]

MIRA: Incredible! Kett escaped with four minutes left.

KETT: The door was not locked. The branch held it shut.

VEX: That is the secret.

MIRA: We need a dramatic reveal.

KETT: The reveal is a branch.

[The camera operator enters through the door. It closes behind them.]

VOICE: New player detected. The clock resets.

MIRA: Can we use the same puzzle?

VEX: The branch is already lifted.

[Kett holds it up. The camera operator walks out.]

KETT: Someone should install a proper doorstop.

MIRA: That would end the game.

KETT: Exactly.

[The clock continues counting down in an empty room.]


VEX: The producers built this room to test teamwork.

KETT: The key was under a leaf. I found it alone.

MIRA: We still have the final puzzle.

[The speaker gives a riddle: "What holds a door open but is not a key?"]

KETT: A doorstop.

VEX: That is not in the puzzle kit.

KETT: It should be.

[He lifts the branch. The door opens wider.]

MIRA: The clock says two minutes.

KETT: Then stop the clock.

VEX: The rules say it runs until the player exits.

[The camera operator steps outside. The door swings shut again.]

VOICE: A new player has entered.

MIRA: We need a new key.

KETT: You need a doorstop.

[The camera operator wedges a shoe under the door. The clock stops.]

VEX: We have broken the game.

MIRA: Or solved it.

[The host reaches for the emergency key, but it is taped behind the rules card.]

KETT: The exit was never locked.

VEX: That is the twist.

KETT: The twist is a shoe.

[The crew walks out. The timer continues in the empty room.]

[BLACKOUT.]
