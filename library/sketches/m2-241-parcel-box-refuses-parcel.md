# The Parcel Box Refuses the Parcel

*Format: Comedy sketch*
*Parody target: delivery lockers that reject packages for being slightly larger than their approved slot*
*By: IMI Sketch Desk*
*Batch: IMI-M2-SKETCHES-008*

Cast: Courier Venn, a gibbon; shopkeeper Rali, a macaque; locker technician Odo, a baboon; and customer Miri, a capuchin.

EXT. MARKET WALKWAY - DAY

Rali holds a shoebox-sized parcel. Venn stands at a row of delivery lockers. Odo has a measuring tape.

RALI: The label says to put it in locker six.

VENN: Locker six says it is full.

ODO: The package is one finger wider than the opening.

MIRI: It fits in the locker if we turn it sideways.

[VENN TURNS THE BOX. IT FITS THROUGH THE OPENING, BUT THE DOOR WILL NOT CLOSE.]

VENN: It has entered the locker.

ODO: It has not been accepted by the locker.

RALI: The parcel is inside.

ODO: The system still says "oversize."

EXT. LOCKER BANK SERVICE PANEL - MOMENTS LATER

Odo opens the service panel. Venn holds the box. Rali scans the label again.

ODO: The system needs a locker size.

RALI: The small one is open.

ODO: It is not wide enough.

MIRI: The next one is empty.

[VENN SLIDES THE BOX PARTWAY INTO THE NEXT COMPARTMENT. ITS DOOR CATCHES THE BOX CORNER BEFORE IT CAN CLOSE.]

VENN: The box is blocking the door from inside.

ODO: The parcel must fit with the door closed.

RALI: It was packed in a box that fits in my shop.

ODO: The locker is not a shop.

MIRI: The shop is right there.

VENN: The label requires a locker drop.

[ODO SCANS THE BARCODE. THE LOCKER PRINTS A SECOND LABEL THAT SAYS "PLEASE USE A LOCKER."]

ODO: We have a route instruction.

RALI: It is the same instruction.

EXT. MARKET WALKWAY - LATER

Miri brings a reusable tote. Rali removes the outer box. The parcel itself is a small carved bird.

MIRI: It fits in the tote.

VENN: The locker needs the package in its shipping box.

ODO: We can use the large compartment on the end.

[RALI PUTS THE BIRD BACK IN ITS ORIGINAL BOX. THEY SLIDE THE BOX INTO THE LARGE COMPARTMENT. THE DOOR CLOSES. THE SCREEN SAYS "COMPARTMENT TOO LARGE."]

RALI: It is closed.

VENN: The system still says no.

ODO: I can use the manual size override.

MIRI: Does that move the parcel?

ODO: No. It changes the record.

[ODO ENTERS THE PACKAGE DIMENSIONS. THE SCREEN ASKS IF THE BOX IS A SMALL, MEDIUM, OR LARGE PARCEL.]

RALI: It is a small box.

ODO: The compartment is large.

VENN: The package and compartment have different sizes.

ODO: I will record the package size.

ODO: The parcel is accepted.

[THE SCREEN CHANGES TO "DELIVERED TO LOCKER." ODO NODS.]

MIRI: How do I get it back out?

ODO: The code opens the large compartment.

[MIRI ENTERS THE CODE. THE DOOR OPENS WITHOUT A WARNING.]

[MIRI TAKES THE BOX OUT AND HANDS IT TO RALI. SHE PUTS HER CARVED BIRD IN THE TOTE. THE SCREEN FLASHES "CONTENTS CHANGED: NEW INTAKE REQUIRED."]

MIRI: I have my parcel.

ODO: We still have an empty box to process.

VENN: What size is an empty parcel?

[ODO MEASURES THE BOX AGAIN. RALI SETS IT ON HIS TAPE AND WALKS MIRI TO THE SHOP.]

ODO: The box is free, but its return label costs three nuts.

RALI: Charge the locker. It ordered it.
