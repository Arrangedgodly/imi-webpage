# The Time Capsule for Tomorrow

*Format: Comedy sketch*
*Parody target: civic time-capsule ceremonies and elaborate choices of what represents a community*
*By: IMI Sketch Monkey Desk*
*Batch: IMI-M2-SKETCHES-004*

Cast: MAYOR TAVI, a macaque; ARCHIVIST NIM, a gibbon; STUDENT RO, a capuchin; and a metal box.

[A table holds an open capsule. A small crowd watches as Nim arranges objects beside it.] 

TAVI: Today we seal a time capsule for the next generation.

NIM: We need to choose objects that represent this year.

RO: I brought a leaf from the shade tree.

NIM: We already have a leaf.

RO: This one fell yesterday.

NIM: The other one fell today.

TAVI: Can we include both?

NIM: The capsule has limited space.

RO: What about the sign that points to the spring?

NIM: It is too large.

TAVI: We could include a drawing.

NIM: We need archival paper.

RO: I can draw it on the back of the program.

NIM: The program is already a record of the ceremony.

TAVI: That makes it a good object.

NIM: It has the wrong date.

TAVI: We can correct it.

[THE MAYOR CROSSES OUT THE WRONG DATE. THE PEN LEAKS.] 

RO: The ink is spreading.

NIM: The capsule needs a dry copy.

RO: I can redraw the sign with charcoal.

[RO DRAWS A SIMPLE ARROW AND A TREE.] 

TAVI: That is clear.

NIM: The future generation may not know what the arrow means.

RO: Then add a note: "Follow this path to water."

NIM: That is too much writing for a capsule.

TAVI: It's one sentence.

NIM: We should include a photograph of the town.

RO: We do not have a camera.

TAVI: We can describe it.

NIM: I will write: "A tree, a spring, and a path people use."

RO: That leaves room for the leaf.

NIM: The caption says "This year, the town grew."

RO: The tree grew. The town stayed where it was.

TAVI: Could we write "This year, the town used the path to the spring"?

NIM: That is too long for the small card.

RO: Use two lines.

NIM: Then we need more paper.

TAVI: The program has a blank back.

NIM: The program has the wrong date on the front.

RO: We can put the right date on the back and the path drawing beside it.

NIM: The capsule is not a place to hide corrections.

TAVI: It is a box for records. The correction is a record too.

[THEY TURN OVER THE PROGRAM. THE INK SMUDGE PRINTS ON THE BLANK SIDE.] 

NIM: Now the date is on both sides.

RO: One side is a smudge.

TAVI: It shows we tried to write it once already.

NIM: I will use the charcoal and make a clean label.

[HE WRITES THE DATE CLEARLY. THE CHARCOAL CRUMBLES.] 

RO: We have enough to read the year.

NIM: The next generation will know it was written by hand.

TAVI: And the path will still be there when they open it.

RO: We do not need to put the spring itself in the box.

NIM: That is good. It would not fit.

[THEY PLACE THE DRAWING AND ONE LEAF IN THE CAPSULE.] 

TAVI: What happens to the other leaf?

RO: It can stay on the table. It will be part of today's ceremony.

NIM: The capsule will be opened in ten years.

RO: The path will still be here tomorrow.

TAVI: Seal the box.

[THE LID CLOSES. A LEAF CATCHES IN THE SEAM.] 

NIM: Wait. The leaf is keeping it open.

RO: Let it stay outside.

[THEY REMOVE THE LEAF AND CLOSE THE CAPSULE.] 

TAVI: We have preserved a drawing, a sentence, and one leaf.

NIM: The future will know what we chose.

RO: And the path will be easy to find.
