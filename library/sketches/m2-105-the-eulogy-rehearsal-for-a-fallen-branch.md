# The Eulogy Rehearsal for a Fallen Branch

*Format: Comedy sketch*
*Parody target: solemn memorial formats applied to a useful branch*
*By: IMI Sketch Monkey Desk*
*Batch: IMI-M2-SKETCHES-004*

Cast: SPEAKER ODO, a macaque; ORGANIZER LUX, a gibbon; GARDENER NIM, a capuchin; and a fallen branch.

[A small gathering stands beside a branch resting near the path. Lux holds a folded program.] 

LUX: We have gathered to honor the branch that fell in last night's wind.

NIM: It fell away from the path. No one was hurt.

ODO: It gave shade to the water dish for many seasons.

LUX: Please share a memory.

NIM: I used it to hang a basket while I filled the dish.

ODO: I sat beneath it when the afternoon was hot.

LUX: It was a generous branch.

NIM: It also dropped leaves into the water.

LUX: We should keep the remarks respectful.

NIM: That is respectful. The leaves were easy to remove.

ODO: We can mention the work it gave us.

LUX: The ceremony includes a moment of silence.

[THE GROUP STANDS QUIETLY. A BIRD LANDS ON THE BRANCH.] 

NIM: The branch is still useful.

LUX: The bird has interrupted the silence.

ODO: The bird is resting.

LUX: We should proceed to the final reading.

NIM: The branch can be cut into supports for the new shade frame.

LUX: That sounds like a practical matter.

ODO: It can be part of the remembrance. The branch supported the dish; now it can support the frame.

LUX: We can say that in the program.

NIM: We do not need a program for the branch.

[THE BIRD HOPS TO A HIGHER PART OF THE BRANCH.] 

ODO: It is still holding weight.

LUX: The branch has not entirely left us.

NIM: It has fallen. We should move it before it rolls back onto the path.

LUX: Before we move the branch, should we take a final photograph?

NIM: We already have several.

ODO: The bird is still sitting on it.

LUX: The program says we will place flowers beside the branch.

NIM: Flowers will get stepped on while we carry it.

ODO: We can leave the branch until the bird flies away.

[THE GROUP WAITS. THE BIRD PECKS AT A LOOSE PIECE OF BARK.] 

LUX: It is taking a piece.

NIM: That can go into the nest.

ODO: The branch has helped another animal after falling.

LUX: Shall I add that to the remembrance?

ODO: You can say it once. We do not need to make the bird part of the ceremony.

NIM: The bird is finished. We can move the branch now.

[THE BIRD FLIES TO A NEARBY TREE. THE GROUP LIFTS THE BRANCH TO A WORKBENCH.] 

LUX: The path is clear again.

ODO: The branch will become supports for the shade frame.

NIM: We should cut only the pieces that fit. The rest can return to the garden bed.

LUX: We have honored the branch and found a use for it.

ODO: We have also made room for people to pass.

NIM: The tea can happen after the work is done.

LUX: I will change the schedule.
