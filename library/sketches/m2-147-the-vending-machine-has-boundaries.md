# The Vending Machine Has Boundaries

*Format: Comedy sketch*
*Parody target: workplace vending machine policies and corporate wellness messaging applied to a machine that will not release a snack*
*By: IMI Sketch Monkey Desk*
*Batch: IMI-M2-SKETCHES-005*

Cast: Employee Fia, a macaque; facilities manager Odo, a baboon; wellness coach Neri, a gibbon; and machine voice.

[A VENDING MACHINE HAS ONE BANANA LEFT. FIA PRESSES THE BUTTON.]

MACHINE VOICE: Please make a healthy choice.

FIA: I chose the banana.

[THE MACHINE HUMS BUT DOES NOT DROP IT.]

ODO: We have a wellness upgrade.

NERI: It helps employees pause before snacking.

FIA: I have paused.

MACHINE VOICE: Please reflect on your hunger.

FIA: I am hungry.

[ODO OPENS THE SERVICE PANEL.]

ODO: The banana is stuck.

NERI: The machine is encouraging patience.

[THE MACHINE DISPLAYS A TIMER: 10 MINUTES.]

FIA: My break is five.

NERI: You can use the time to breathe.

[FIA BREATHES. THE TIMER CONTINUES.]

ODO: We need a maintenance code.

NERI: The code is "mindful."

ODO: That is not a code.

[THE MACHINE BEEPS.]

MACHINE VOICE: Please select a wellness goal.

FIA: Retrieve my banana.

[THE MACHINE DISPENSES A BROCHURE.]

FIA: I did not ask for this.

NERI: It is a resource.

[ODO TAPS THE SIDE. THE BANANA DROPS.]

MACHINE VOICE: Thank you for making a choice.

[FIA TAKES THE BANANA. THE MACHINE BEEPS AGAIN.]

MACHINE VOICE: Please record your satisfaction.

FIA: Satisfied.

[THE MACHINE PRINTS A SURVEY.]

ODO: It needs paper.

[FIA EATS THE BANANA. THE MACHINE DISPLAYS "ITEM OUT OF STOCK."]

NERI: The machine can help you choose something else.

FIA: There is nothing else.

[ODO CLOSES THE PANEL.]

ODO: I will add a second banana tomorrow.

MACHINE VOICE: Please schedule a wellness check.

[FIA WALKS AWAY. NERI STANDS BESIDE THE MACHINE, BREATHING SLOWLY.]

NERI: I am waiting for the next snack.


[FIA RETURNS TO THE MACHINE WITH THE BROCHURE.]

FIA: I need to recycle this.

MACHINE VOICE: Please select a wellness pathway.

FIA: The recycling bin.

[THE MACHINE LIGHTS UP THE BUTTON MARKED "PAUSE."]

ODO: That button is stuck too.

NERI: We can file a facilities ticket.

ODO: The ticket system is offline.

FIA: Can I put the brochure in the machine?

[THE MACHINE BEEPS AND OPENS THE COIN RETURN.]

MACHINE VOICE: Thank you for your feedback.

[FIA DROPS THE BROCHURE IN. ODO RETRIEVES IT.]

ODO: It is not a bin.

NERI: It has accepted the paper.

[FIA PRESSES THE BANANA BUTTON AGAIN. NOTHING HAPPENS.]

FIA: The machine has set a boundary.

ODO: It has run out of bananas.

NERI: We will replace the banana after the repair.

FIA: I will bring my own snack tomorrow.

[THE MACHINE DROPS THE SURVEY INTO THE EMPTY DISPENSER.]

[ODO PUTS A SERVICE TAG ON THE PANEL.]

ODO: The repair request is in.

MACHINE VOICE: Thank you for your patience.

FIA: My break is already over.


[THE WELLNESS COACH TURNS OFF THE MACHINE.]

FIA: That was a healthy choice.
