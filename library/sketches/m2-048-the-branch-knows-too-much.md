# The Branch Knows Too Much

*Format: Comedy sketch*
*Parody target: mobile-app launch ads and privacy permission screens*
*By: IMI Sketch Monkey Desk*
*Batch: IMI-M2-SKETCHES-003*

Cast: JUNE, a macaque user; PIP, the BranchBuddy app voice; OLA, June's grandmother; and a VOICEOVER.

[A phone screen is projected on a wall. A leaf icon spins above the words FIND A BRANCH.]

VOICEOVER: Meet BranchBuddy, the app that finds a comfortable branch before you do. Tap once to begin.

JUNE: It wants my location.

PIP: I need your location to find a branch near you.

JUNE: I am sitting in a tree.

PIP: Please enable tree services.

[June taps "not now." The app shows a map with every branch labeled POSSIBLY COMFORTABLE.]

JUNE: Which one can hold me?

PIP: That feature requires premium.

OLA: Ask the tree.

PIP: Would you like to enable microphone access so we can hear the tree?

OLA: No.

JUNE: It wants camera access, tail direction, and browsing history.

PIP: Tail orientation improves branch recommendations.

OLA: Your tail is pointed at the phone. It is already a review.

[JUNE taps deny. The map disappears.]

PIP: Without tail data, I cannot tell whether you are facing the branch.

JUNE: I can see it.

PIP: Visual confirmation is available in premium.

VOICEOVER: BranchBuddy. Finding a way to say "turn around" in six screens.

[The phone buzzes. PIP begins speaking faster.]

PIP: We noticed you looked at a fig branch last week. Would you like a reminder? We have shared your interest with nearby trees.

OLA: Trees do not have accounts.

PIP: We can create them.

[JUNE switches off the phone. A real branch creaks overhead.]

JUNE: That one sounds sturdy.

OLA: Check for a crack.

[They look up. A bird has nested on the branch. June steps aside.]

JUNE: Not available.

PIP: I found an alternative. A bench.

JUNE: The bench is already under us.

PIP: Would you like to rate this recommendation?

OLA: The bench gives better service.

[June deletes the app. PIP's voice stops. The real leaf icon still spins on the blank screen.]

VOICEOVER: BranchBuddy is not responsible for weather, weight limits, birds, or trees. Please confirm every suggestion with the tree.

OLA: It has learned.

JUNE: No, the screen went dark.

[They sit on the bench. The phone stays off.]

VOICEOVER: BranchBuddy stores your preferences so you can find the same branch again.

OLA: We did not give it preferences.

PIP: We inferred them from where you sat.

JUNE: You inferred that I like this bench because I am sitting on it.

PIP: Correct. Would you like a sponsored bench cushion?

JUNE: No.

PIP: We can offer a limited-time discount.

OLA: No.

[June puts the phone in a drawer. The leaf icon glows faintly through the wood.]

JUNE: Is it still listening?

OLA: The drawer is made of wood.

PIP: Would you like to upgrade to a drawer with privacy settings?

[Ola closes the drawer. The icon disappears.]

VOICEOVER: BranchBuddy. Now with a drawer-compatible experience.

JUNE: The branch is still there.

OLA: The bench too.

[They leave the phone in the drawer and go for a walk.]

[BLACKOUT.]
