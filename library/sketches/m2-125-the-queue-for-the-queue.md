# The Queue for the Queue

*Format: Comedy sketch*
*Parody target: online reservation culture and waiting lists for a neighborhood seed exchange*
*By: IMI Sketch Monkey Desk*
*Batch: IMI-M2-SKETCHES-005*

Cast: Clerk Omi, a capuchin; applicant Tavi, a macaque; registrar Bex, a gibbon; and helper Nill, a lemur.

[A SIGN READS "SEED EXCHANGE REGISTRATION. TAKE A NUMBER." THE NUMBER DISPENSER IS EMPTY.]

TAVI: I need a number.

OMI: First take a number from the queue for numbers.

TAVI: Where is that queue?

BEX: It starts behind the sign.

[TAVI WALKS BEHIND IT. THE LINE GOES AROUND THE ROOM.]

NILL: You are now number seven.

TAVI: Seven in which line?

NILL: The line for the number queue.

[TAVI TAKES A SEAT. BEX HANDS HIM A FORM.]

BEX: Fill this out while you wait.

TAVI: It asks for my number.

OMI: Write "pending."

TAVI: It also asks what seeds I am bringing.

OMI: You can answer that after getting a number.

[TAVI LOOKS IN HIS BAG. A MONKEY TAKES ONE SEED AND HIDES IT IN THE FOLDED FORM.]

TAVI: My inventory changed.

BEX: Please report all changes in inventory.

[TAVI FILLS A SECOND FORM. NILL STAMPS IT "WAITING FOR REVIEW."]

TAVI: How long will review take?

OMI: We have an appointment to estimate the wait.

[THE APPOINTMENT BOARD READS "NEXT AVAILABLE: NEXT MONTH."]

TAVI: The seed exchange is tomorrow.

BEX: We can put you on the cancellation list.

TAVI: Do I need a number for that?

OMI: Yes. The cancellation list number is issued at the other desk.

[THE OTHER DESK IS EMPTY. THE CLERK'S CHAIR IS IN THE QUEUE.]

TAVI: Is the chair waiting?

NILL: It is waiting for its turn to be cleaned.

[THE LITTLE MONKEY RETURNS THE SEED, THEN TAKES ANOTHER.]

BEX: Please report the inventory change.

TAVI: I have one seed again.

OMI: We need a confirmation for that.

[TAVI SETS THE SEED ON THE COUNTER. EVERYONE LOOKS AT IT.]

TAVI: Can I exchange this now?

[OMI CHECKS THE FORM. BEX CHECKS THE BOARD. NILL CHECKS THE LINE.]

OMI: Yes. The seed has already been accepted.

TAVI: What number am I?

BEX: You are the only applicant.


[OMI TAKES THE NUMBER BACK.]

OMI: The number is for the next exchange.

TAVI: I am here for today's exchange.

BEX: Today's exchange is already underway.

[TAVI PICKS UP A SEED. THE MONKEY RETURNS THE OTHER ONE TO HIS BAG.]

TAVI: I have my seed back.

NILL: I can stamp the bag.
[TAVI PUTS THE NUMBER IN HIS POCKET BESIDE THE SEED.]


TAVI: I can use this number next year.


[THE FORM IS FILED IN A DRAWER MARKED "NEXT YEAR."]


BEX: You may keep the number.


[THE SEED EXCHANGE CONTINUES WITHOUT A QUEUE. TAVI HELPS SORT THE SEEDS BY SIZE.]


[TAVI TAKES THE SEED AND WALKS TO THE EXCHANGE TABLE. NILL HANDS HIM A NUMBER.]

NILL: Number one.

TAVI: I already left the queue.

NILL: The number is valid for next year.
