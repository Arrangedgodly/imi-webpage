# The Restaurant Menu Is an Escape Room

*Format: Comedy sketch*
*Parody target: escape-room puzzles and themed dining, where a hungry customer has to solve a clue before ordering lunch*
*By: IMI Sketch Monkey Desk*
*Batch: IMI-M2-SKETCHES-014*

Cast: SERVER, a macaque; CUSTOMER, an orangutan; CHEF, a baboon; PUZZLE DESIGNER, a gibbon; BUSSER, a capuchin.

[A restaurant table. A menu is chained to a wooden box. The customer holds a fork and looks at the server.] 

CUSTOMER: I would like the lentil soup.

SERVER: First solve the menu.

CUSTOMER: Is that optional?

PUZZLE DESIGNER: The theme is a treasure kitchen. Read the riddle on the first page.

[The customer reads: "I am round, I have layers, and I make you cry." The chef looks up from the pass.] 

CUSTOMER: An onion.

PUZZLE DESIGNER: Correct. Now enter the word into the box.

[The designer opens a small latch. Inside is another menu, this one for dessert.] 

CUSTOMER: I still wanted soup.

SERVER: Soup is on the lunch menu, page two.

[The customer turns the page. A tiny combination lock is attached to the spine.] 

BUSSER: It is supposed to be a three-digit code.

CHEF: The soup is getting cold.

[The customer notices three dots beside the soup description: hot, warm, and cold. They rotate the lock to H-W-C, but it only uses numbers. The server brings a bowl of alphabet pasta and points to the menu.] 

SERVER: The code is the price of the soup.

CUSTOMER: It's twelve dollars.

[The customer enters 1-2-0. The lock opens. The menu falls flat on the table.] 

CUSTOMER: Does the kitchen have to solve a puzzle before cooking?

CHEF: No. I have been making the soup while you read.

[The server sets the soup down. The customer takes a spoonful. The puzzle designer points to a final card under the bowl.] 

PUZZLE DESIGNER: One last clue unlocks the napkin ring.

CUSTOMER: The napkin is free.

BUSSER: It's a paper napkin. You can take it.

[The designer takes the card back. The server removes the chain from the menu so the customer can pass it to the next table.] 

SERVER: We are changing the menu. The soup stays on page two, no lock.

PUZZLE DESIGNER: What if we keep one riddle?

CHEF: Keep it on the dessert menu. The kitchen can still serve lunch.

[The customer finishes the soup. The busser clears the bowl and leaves a plain paper menu.] 

CUSTOMER: I can order tea without a code?

SERVER: Yes.

[The customer orders tea. The server writes it down without a riddle. The designer walks away carrying the unused wooden box.] 

[The server slides a plain menu to the next table. The puzzle designer tries to hand over the locked wooden box, but the busser has already moved it to the dessert counter.] 

BUSSER: The box can hold napkins. It does not need a code.

PUZZLE DESIGNER: The code was part of the experience.

CUSTOMER: The soup was the experience.

[The chef brings out a fresh bowl for the next guest. No one waits for a clue before serving it.] 

FINAL IMAGE: The unlocked menu lies beside an empty soup bowl while the puzzle box waits by the dessert station.
