# The Library Has a Branch Fee

*Format: Comedy sketch*
*Parody target: library late fees, quiet rules and book returns in a literal canopy branch*
*By: IMI Sketch Monkey Desk*
*Batch: IMI-M2-SKETCHES-005*

Cast: Librarian Dena, a macaque; reader Veli, a gibbon; assistant Odo, a baboon; and a small monkey.

[A LIBRARY COUNTER SITS IN A TREE HOLLOW. A SIGN READS "QUIET PLEASE." VELI RETURNS A BOOK.]

DENA: This book is three days late.

VELI: I was reading it in the branch.

ODO: The branch is part of the library.

VELI: I never left.

DENA: The due date was written on the leaf.

[VELI SHOWS A LEAF. THE INK HAS FADED.]

DENA: I cannot read it.

ODO: The late fee is one acorn per day.

VELI: I have three acorns.

[HE PUTS THEM ON THE COUNTER. A SMALL MONKEY TAKES ONE.]

ODO: The fine is now two acorns.

DENA: The monkey is not the library.

[THE MONKEY CLIMBS TO A HIGHER BRANCH WITH THE ACORN.]

VELI: It is using the library.

DENA: We have a separate branch-use policy.

[ODO PULLS A SECOND BOOK FROM THE RETURN SLOT.]

ODO: This one is early.

DENA: Then the reader gets a credit.

VELI: I returned it yesterday.

DENA: It was due next week.

[THE MONKEY TAKES THE BOOK AND HIDES IT IN A HOLLOW.]

ODO: The book is now overdue.

DENA: Who checked it out?

[EVERYONE LOOKS AT THE MONKEY.]

VELI: It cannot read.

[THE MONKEY OPENS THE BOOK UPSIDE DOWN.]

DENA: It is studying the pictures.

ODO: Do pictures have a due date?

DENA: All library materials have a due date.

[THE MONKEY TURNS A PAGE. A LEAF FALLS OUT.]

VELI: That is my bookmark.

DENA: It is now part of the collection.

[THE LIBRARIAN STAMPS THE BOOK. THE STAMP IS INKED WITH THE MONKEY'S HANDPRINT.]

ODO: The return has been confirmed.

DENA: The fee is paid.

[DENA OPENS THE CATALOG.]

DENA: The book is listed under local history.

VELI: It is about birds.

ODO: Birds are local.

[THE MONKEY TURNS THE BOOK UPSIDE DOWN AGAIN.]

DENA: It appears to prefer the back cover.

VELI: Can I pay the fine with a book?

DENA: We do not accept books as payment.

ODO: We accept acorns.

[THE MONKEY DROPS AN ACORN INTO THE FINE JAR.]

DENA: The payment has arrived.

VELI: It did not owe a fine.

DENA: It may be paying for the book it checked out.

[THE MONKEY OPENS THE BOOK TO A PICTURE OF A NEST.]

ODO: It has found its subject.

DENA: The book can stay with the reader until it is due.

VELI: Which reader?

[THE MONKEY SITS ON THE BOOK.]

DENA: We will record it as a group reading.

[THE MONKEY RETURNS THE ACORN. DENA PUTS IT IN A JAR LABELED "LATE FEES."]

VELI: Can I borrow another book?

DENA: Yes, but keep it in the branch.

[THE MONKEY TAKES THE NEW BOOK. EVERYONE SHUSHES IT.]
