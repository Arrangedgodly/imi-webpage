# The Badge Ceremony for Tying Knots

*Format: Comedy sketch*
*Parody target: youth award ceremonies that make a practical skill wait through an elaborate sequence of speeches and badges*
*By: IMI Sketch Desk*
*Batch: IMI-M2-SKETCHES-007*

Cast: Scout Leader Etta, a macaque; Scout Piri, a gibbon; Parent Domo, a baboon; and Emcee Vala, a capuchin.

INT. SCOUT HALL - AFTERNOON

A length of rope lies on a table. Piri waits beside it. Etta holds a small knot badge. Vala checks a long program.

VALA: We will begin with the opening remarks, then the history of knots, then the badge presentation.

PIRI: I can tie the knot now.

ETTA: Show us the bowline.

[PIRI TIES A CLEAN BOWLINE AROUND A POST.]

DOMO: That is the one for rescue loops.

VALA: Please hold applause until the full introduction.

PIRI: I have another knot to tie.

DOMO: The tent straps are loose.

ETTA: Piri can show a taut-line hitch.

VALA: Is that in the ceremony sequence?

PIRI: It is on the skills list.

[PIRI TIES THE STRAP TO A POST. THE TENT STOPS FLAPPING IN THE DRAFT.]

DOMO: Now we can hear the speaker.

VALA: Was that a demonstration or an interruption?

VALA: The next item is a two-minute address from the district chair.

DOMO: The tent is flapping again.

ETTA: Piri can secure it while the address begins.

PIRI: The clove hitch is still holding.

[THE TENT SETTLES. VALA'S PROGRAM STOPS FLUTTERING IN THE DRAFT.]

VALA: I can read now.

VALA: We can begin the welcome.

INT. SCOUT HALL - LATER

Vala reads from the program. Etta holds the badge. Piri's rope is now tied into three useful knots.

VALA: The scout has demonstrated a bowline, a clove hitch, and a square knot.

PIRI: I also tied the program to the chair so it would not slide.

[THE PROGRAM IS SECURELY TIED TO THE CHAIR. VALA TUGS IT. THE CHAIR MOVES.]

VALA: That was not on the checklist.

ETTA: It shows initiative.

DOMO: Can we untie it? The chair is needed for the next speaker.

PIRI: I can release the clove hitch.

[THE PROGRAM COMES FREE. VALA CONTINUES READING.]

VALA: Before the badge, we have a message from the regional coordinator.

PIRI: The message is on the back of the badge.

INT. SCOUT HALL - BADGE TABLE

Etta pins the badge to Piri's shirt. Vala raises a ceremonial rope. Domo waits beside the door with a packed tent.

ETTA: You earned the knot badge by showing the knots and explaining their uses.

PIRI: Thank you. I can help tie down the tent now.

VALA: Please stay for the group photograph.

DOMO: The tent is already tied to the car.

[THE CEREMONIAL ROPE IS STILL TIED TO THE PROGRAM. VALA PULLS IT, AND THE ENTIRE PROGRAM FOLDS SHUT.]

VALA: That is the end of the ceremony.

PIRI: I can untie it.

[THEY LEAVE WITH THE TENT SECURE. VALA CARRIES THE BADGE CHECKLIST OUT, STILL ATTACHED TO THE ROPE.]
