# The Award Show's Envelope Is Empty

*Format: Comedy sketch*
*Parody target: suspenseful awards ceremonies, announcers stretching a reveal, and prize envelopes with no card inside*
*By: IMI Sketch Monkey Desk*
*Batch: IMI-M2-SKETCHES-015*

Cast: HOST, a gibbon; PRESENTER, a baboon; STAGE MANAGER, an orangutan; NOMINEE ONE, a macaque; NOMINEE TWO, a capuchin.

[A small award stage. The presenter holds a sealed envelope. Two nominees sit beside a trophy. The host stands by a countdown clock.]

HOST: The winner will be announced after a short pause.

PRESENTER: I have opened the envelope.

[The presenter turns it upside down. Nothing falls out.]

STAGE MANAGER: The card is missing.

NOMINEE ONE: Is this the pause?

ACT ONE

[The host begins filling time with a speech about artistic excellence. The clock ticks. The stage manager searches the podium and finds a stack of blank cards. The presenter says the envelope had a name inside during rehearsal.]

PRESENTER: I saw it before the show.

HOST: Then you know the winner.

PRESENTER: I saw a name. I did not read it.

[The stage manager checks the envelope's flap. The card is stuck to the adhesive. They lift it carefully, but the card tears in half. The presenter holds the two pieces up to the light.]

NOMINEE TWO: I see an initial.

NOMINEE ONE: I see the back of the card.

[The host asks the nominees not to guess. The stage manager finds a duplicate card in the desk, but it is from last year's ceremony. The presenter starts to announce the wrong name. The host covers the microphone.]

HOST: We need the current results.

[The stage manager calls the awards clerk backstage. The clerk confirms the winner on a signed sheet. The presenter asks whether the result can be announced without the envelope. The host says the pause must remain dramatic. They put the signed sheet in a new envelope. It will not fit because the trophy receipt is inside.]

STAGE MANAGER: The receipt is not the winner.

PRESENTER: It has more words.

[The host gives the audience a brief explanation: the envelope was empty, the signed result is confirmed, and the award will be presented. The nominees wait. The stage manager places the new card inside and seals it once. The presenter opens it.]

[The stage manager checks the signed results sheet against the printed program. Nominee Two's name is misspelled in the program, so the host asks the winner to spell it for the audience. The presenter holds the trophy while the stage manager corrects the program in pen. Nominee One asks if the next envelope has a card.]

STAGE MANAGER: It has two.

HOST: We will open one at a time.

ACT TWO

PRESENTER: The award goes to Nominee Two.

[Nominee Two accepts the trophy. Nominee One applauds. The host lets the clock stop. The stage manager puts the old blank envelope in the recycling box.]

NOMINEE TWO: I was prepared for a longer pause.

HOST: We have another category.

FINAL IMAGE: The next presenter checks the envelope by touch before stepping onto the stage.
