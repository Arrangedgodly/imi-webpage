# The Library's Automatic Return Slot Rejects a Book

*Format: Comedy sketch*
*Parody target: automated self-service kiosks that treat routine exceptions as suspicious user behavior*
*By: IMI Sketch Desk*
*Batch: IMI-M2-SKETCHES-008*

Cast: Librarian Nara, a gibbon; patron Odo, a baboon; patron Miri, a capuchin; and technician Kito, a macaque.

INT. LIBRARY ENTRY - EVENING

Odo approaches the book return slot with a slim book. The machine flashes INSERT BOOK. He slides it in; the rollers push it back out.

ODO: It says return your book.

NARA: It has returned it to you.

KITO: The slot is designed for hardcovers.

MIRI: It is a paperback.

[Odo tries again. The book emerges with a receipt reading ITEM TOO FLEXIBLE.]

ODO: The book is flexible.

NARA: It is also due today.

INT. ENTRY - MOMENTS LATER

Kito opens the service panel. Miri reads the screen. Odo holds the paperback flat with both hands.

KITO: The sensor is detecting the cover as two books.

MIRI: It has one cover.

KITO: The machine sees a front and a back.

NARA: It should see one book.

[The machine prints another receipt: PLEASE REMOVE EXTRA ITEM. Odo checks his hands.]

ODO: I have one item.

MIRI: The machine may be counting your fingers.

[Odo folds his hands behind his back. The slot accepts nothing.]

INT. ENTRY - LATER

Kito adjusts the sensor. The screen now reads: PLACE BOOK IN CENTER. Odo centers the book precisely. The rollers pull it in, then stop with half the book visible.

KITO: It is processing.

NARA: It is holding the book.

MIRI: Maybe it wants to read it first.

[The machine flashes a progress bar. It advances one pixel, pauses, then displays a question: DID YOU ENJOY THIS BOOK?]

ODO: Yes.

[The screen says THANK YOU. The book slides back out.]

NARA: It still has not accepted the return.

KITO: It has completed the survey.

INT. LIBRARY ENTRY - MOMENTS LATER

Kito places a hardcover in the slot. It slides in at once and the display flashes RETURN COMPLETE.

KITO: It works perfectly.

NARA: For hardcovers.

[The slot immediately prints a receipt and feeds it back out. Kito checks the book; it is still in his hands.]

MIRI: It has returned the receipt.

ODO: The machine is very good at returns.

KITO: It is returning everything except the book.

INT. LIBRARY DESK - CLOSING

Nara opens a manual return ledger. Odo places the book on the counter. Kito stands beside the machine as it continues to display the survey question.

NARA: I will check it in by hand.

ODO: Does the machine need a reason?

NARA: It needs a night off.

[Miri writes a small sign: PAPERBACKS, PLEASE USE THE DESK. She sets it on the machine.]

MIRI: The sign is simple.

KITO: The machine has a feedback form.

[The slot accepts the sign, prints a receipt, and gives it back.]

NARA: It has processed the instruction.

ODO: Did it enjoy it?

[The screen flashes YES. Everyone looks at the machine.]

KITO: That is the first honest answer tonight.
