# The Auction of One Acorn

*Format: Comedy sketch*
*Parody target: auction broadcasts and escalating bids for an ordinary object*
*By: IMI Sketch Monkey Desk*
*Batch: IMI-M2-SKETCHES-005*

Cast: Auctioneer Poro, a baboon; bidders Mina, a macaque, and Veli, a gibbon; clerk Nari, a capuchin; and a small monkey.

[AN AUCTION TABLE HOLDS ONE ACORN.]

PORO: We begin at one leaf.

MINA: I bid two.

VELI: Three.

NARI: The acorn is still one acorn.

PORO: It has excellent provenance.

MINA: It fell from the tree outside.

PORO: A local origin.

[THE SMALL MONKEY TAKES THE ACORN.]

NARI: The lot has been removed.

PORO: We will accept bids for the right to recover it.

VELI: I bid four.

MINA: I bid five.

[THE MONKEY CRACKS THE ACORN AND EATS THE NUT.]

PORO: The lot has been consumed.

NARI: Can we auction the shell?

PORO: We can restart at one leaf.

MINA: I bid one shell.

VELI: Two.

[THE MONKEY TAKES THE SHELL.]

NARI: The lot has moved again.

PORO: We will sell the empty table.

MINA: I bid the table.

VELI: I bid one chair.

[THE MONKEY CLIMBS ON THE TABLE.]

NARI: The table is occupied.

PORO: The bidder has entered the lot.

MINA: Does that count as a bid?

NARI: It counts as possession.

[THE MONKEY LEAVES. THE TABLE IS EMPTY.]

PORO: The highest bidder is the monkey.

VELI: It never bid.

PORO: It took the item.

MINA: That is not how an auction works.

[THE CLERK CLOSES THE LOT BOOK.]

NARI: The acorn has been sold, eaten, and returned to the forest.

PORO: A successful auction.

[THE BIDDERS LEAVE. THE AUCTIONEER LOOKS AT THE EMPTY TABLE.]

PORO: Does anyone want the table?


[THE AUCTIONEER OPENS A SECOND LOT: A SMALL PAPER LABEL.]

PORO: This label reads "one acorn." Opening bid, one leaf.

MINA: That is the label from the first lot.

NARI: It has historical significance.

VELI: I bid two leaves.

[THE MONKEY RETURNS AND TAKES THE LABEL.]

PORO: We have a competing bidder.

MINA: It is not bidding. It is carrying things.

NARI: The auction is now mobile.

[THE MONKEY PUTS THE LABEL ON THE TABLE. PORO STRAIGHTENS IT.]

PORO: The lot has been returned to the floor.

VELI: I bid the floor.

PORO: We cannot sell the room.

NARI: The room is rented.

[THE MONKEY TAKES THE LABEL AGAIN. THE CLERK TURNS THE LOT BOOK TO A BLANK PAGE.]

NARI: We need a category for items that leave during bidding.

PORO: Call it "active inventory."

[MINA SETS A SECOND ACORN ON THE TABLE.]

MINA: This one is not for sale.

PORO: Then it is the auction monitor.

MINA: I withdraw my bid.

PORO: The table is still available.

NARI: The monkey has taken a seat.

[THE MONKEY RETURNS AND SITS ON THE TABLE. NARI CLOSES THE LOT BOOK.]

NARI: The auction is closed.

PORO: Sold.
