# Rush Hour at the Root Crossing

*Format: Comedy sketch*
*Parody target: traffic-report television and road planning meetings at a narrow path used by several species*
*By: IMI Sketch Monkey Desk*
*Batch: IMI-M2-SKETCHES-005*

Cast: Reporter Tavi, a macaque; planner Rena, a baboon; cyclist Poro, a gibbon; and crossing guard Miri, a capuchin.

[A NARROW PATH RUNS BETWEEN TWO ROOTS. TAVI STANDS IN FRONT OF A TRAFFIC MAP.]

TAVI: We are live at the root crossing, where traffic has stopped.

[THREE MONKEYS CARRY A BRANCH ACROSS THE PATH.]

RENA: The crossing is blocked by a branch.

PORO: It is a shortcut for my bicycle.

MIRI: It is the only path to the water bowl.

[RENA UNFOLDS A PROPOSED DETOUR MAP. THE DETOUR GOES IN A CIRCLE.]

TAVI: The plan adds a loop.

RENA: It separates walkers from riders.

PORO: The branch is still in the path.

MIRI: We can lift it to the side.

[THE GROUP LIFTS THE BRANCH. THE PATH OPENS, BUT THE MAP FALLS INTO THE DUST.]

RENA: The map is out of date.

TAVI: It was printed five minutes ago.

[PORO RIDES THROUGH. A MONKEY CROSSES FROM THE OTHER SIDE.]

MIRI: Stop. There is no signal.

[THE MONKEY CARRIES A BOWL. PORO WAITS.]

TAVI: We have a yield.

RENA: We can install a traffic light.

MIRI: There is no power on the path.

RENA: We can install a bell.

[THE MONKEY RINGS THE BELL. A TROOP RESPONDS FROM THE TREES.]

TAVI: The bell has called more traffic.

[THE TROOP CROSSES TO THE WATER BOWL. PORO WALKS HIS BICYCLE THROUGH.]

RENA: The map needs a walking lane.

MIRI: The whole crossing is a walking lane.

[RENA DRAWS A LINE ON THE MAP. THE LINE CROSSES THE ROOT.]

TAVI: The root is not removable.

RENA: We can mark it.

[MIRI TIES A BRIGHT RIBBON TO THE ROOT. EVERYONE CAN SEE IT.]

PORO: I can steer around that.

[THE MONKEYS CARRY THE BOWL BACK. TAVI REPORTS TO CAMERA.]

TAVI: The jam has cleared without a detour.

RENA: We still need a plan for the next branch.

[RENA PUTS TWO CONES BESIDE THE ROOT.]

RENA: Riders can wait here while walkers cross.

PORO: The cones make the path narrower.

MIRI: Put them on the outside edge.

[THEY MOVE THE CONES. A MONKEY WALKS BETWEEN THEM WITH THE BOWL.]

TAVI: The new route is open.

[PORO RIDES SLOWLY. THE FRONT WHEEL CATCHES ON A ROOT.]

PORO: The path needs a warning.

MIRI: The ribbon is on the root.

PORO: It is behind the camera.

[TAVI MOVES THE CAMERA. THE RIBBON IS VISIBLE.]

TAVI: The camera was the obstruction.

RENA: We should add it to the map.

RENA: We need a camera lane.

MIRI: Or the camera can move.

[THE CAMERA CREW BACKS UP. THE CROSSING CLEARS.]

[MIRI MOVES THE RIBBON TO THE OTHER SIDE OF THE ROOT.]

PORO: Now riders can see it sooner.

[THE BRANCH ROLLS BACK INTO THE PATH.]

MIRI: We need the bell again.

[THE TROOP RINGS IT. EVERYONE WAITS.]
