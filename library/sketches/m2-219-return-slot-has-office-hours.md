# The Return Slot Has Office Hours

*Format: Comedy sketch*
*Parody target: public service counters that impose complicated hours on a simple after-hours drop-off*
*By: IMI Sketch Desk*
*Batch: IMI-M2-SKETCHES-007*

Cast: Library Clerk Varo, a macaque; Visitor En, a gibbon; Supervisor Sella, a capuchin; and Night Cleaner Doma, a gorilla.

INT. LIBRARY ENTRY - EVENING

En holds one book. A metal return slot is set into the wall. Varo stands behind a desk with a laminated hours chart.

EN: Can I return this book?

VARO: The desk closes at six. The slot accepts returns until nine.

EN: It is six fifteen.

VARO: The slot is open until nine.

[EN SLIDES THE BOOK INTO THE SLOT. A CLUNK SOUNDS.]

VARO: That was the deposit sound.

EN: Is it returned?

VARO: It will be processed tomorrow.

EN: If I drop off a book before midnight, does it count today?

VARO: The timestamp will record the deposit.

EN: So today.

VARO: It will be visible tomorrow.

SELLA: Those can both be true.

DOMA: I empty the slot at closing. The book will not sleep there.

EN: I was picturing it in a tiny overnight queue.

VARO: The queue is a bin, not a waiting room.

EN: So it is returned now?

VARO: Your account will update tomorrow.

SELLA: The slot says "RETURN BOOKS HERE."

VARO: The sign does not specify account status.

INT. LIBRARY SERVICE DESK - MOMENTS LATER

Sella opens the return hatch. The book sits inside. Varo checks a binder labeled "AFTER-HOURS PROCEDURES."

SELLA: It is in the library.

VARO: We need to log its arrival.

EN: I am standing right here. I returned it.

VARO: The form asks who witnessed the drop.

DOMA: I heard the clunk.

VARO: The cleaner is not authorized to witness returns.

DOMA: I clean this room at night.

SELLA: Can I sign as the desk supervisor?

VARO: Only during desk hours.

EN: What happens if no one signs?

VARO: The book waits in the bin.

DOMA: I can move it to the shelf.

VARO: That would be a shelving action, not a return action.

INT. LIBRARY ENTRY - NIGHT

Doma carries the book to the sorting cart. En still waits by the slot. Sella turns over the hours chart and finds a small note: "After-hours books count as returned at deposit."

SELLA: Here. The rule says the deposit date is the return date.

VARO: The account updates tomorrow.

EN: That is the part I needed to know.

VARO: The counter is closed, but I can explain the rule.

DOMA: And I can put the book on the cart.

[DOMA SLIDES IT ON. THE CART ROLLS AWAY WITH A QUIET RATTLE.]

EN: Done?

SELLA: Done.

VARO: We should put a sign on the slot.

[VARO ADDS THE SMALL NOTE TO THE FRONT. THE WORDS "RETURNS COUNT TODAY" COVER THE HOURS CHART.]

EN: Now the sign answers my question.

VARO: During desk hours, we can print a larger one.
