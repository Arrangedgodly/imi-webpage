# The Front Page Is a Leaf

*Format: Comedy sketch*
*Parody target: local newspaper newsroom urgency and the chase for a headline*
*By: IMI Sketch Monkey Desk*
*Batch: IMI-M2-SKETCHES-004*

Cast: EDITOR SORI, a macaque; REPORTER PEL, a gibbon; PHOTOGRAPHER NIM, a capuchin; and COPY DESK BEE, a lemur.

[A NEWSROOM. A printer feeds out one blank page. Sori circles the word BREAKING.] 

SORI: We need a front-page story by noon.

PEL: The old footpath is open again.

SORI: That happened yesterday.

PEL: It is still open today.

BEE: We have a report that a leaf landed on the notice board.

SORI: Is it the same leaf as yesterday?

NIM: I can photograph it.

SORI: Get an angle that shows scale.

[NIM HOLDS A PENCIL BESIDE THE LEAF. THE PENCIL COVERS IT.] 

NIM: The leaf is smaller than the pencil.

PEL: It fell from the big fig tree.

SORI: We need a headline with movement.

BEE: "Leaf Falls from Tree."

SORI: No urgency.

PEL: "Leaf Arrives at Notice Board."

SORI: That sounds like a delivery.

NIM: It might be wind.

SORI: We need to know why it landed there.

PEL: It was in the way of the notice.

BEE: The notice says the footpath is open.

SORI: Is the path actually open?

PEL: Yes. I walked it.

NIM: We should ask whether the notice is readable from the path.

PEL: It is, unless the leaf covers it.

BEE: The leaf only covers one corner.

SORI: Which corner?

BEE: The word "open."

SORI: That changes the meaning.

PEL: It changes one word. The path is still open.

NIM: I can move the notice higher, above the leaf.

[HE RAISES THE PAPER. THE TAPE PEELS OFF THE BOARD.] 

BEE: Now the whole notice is loose.

SORI: We need a stronger attachment.

PEL: There is twine in the supply box.

[THEY TIE THE NOTICE TO THE BOARD. IT STAYS.] 

SORI: Headline: "Path Open; Notice Secured."

BEE: We have not checked the west end.

PEL: I can walk it again.

SORI: The paper is already printed.

NIM: Then print a small update if you find anything.

SORI: A correction column is not a failure. It is the part that keeps the front page useful.

BEE: Should the leaf go beside the headline?

SORI: Put it in the compost. It has done enough reporting today.

SORI: We should verify.

[THEY WALK TO THE BOARD. THE LEAF FLUTTERS DOWN AND COVERS THE NOTICE.] 

BEE: The leaf has covered the headline.

SORI: That is a development.

PEL: I will move it.

NIM: Wait. I am photographing the notice before it is covered again.

[CAMERA CLICKS.] 

SORI: Now we have a before and after.

BEE: The before is the notice. The after is the leaf.

SORI: We can run both pictures.

PEL: The path is clear and the notice is visible again.

SORI: Then our story is that the path is open and someone put up a useful notice.

BEE: That is not breaking news.

SORI: It is news people can use.

NIM: The leaf is back on the board.

SORI: Put the leaf in the paper as an illustration.

PEL: The printer only printed one blank page.

SORI: Then the front page is a leaf.

[THEY PIN THE LEAF TO THE BLANK PAPER. IT COVERS THE WORD BREAKING.]
