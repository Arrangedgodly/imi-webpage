# Password Reset Support Group

*Format: Comedy sketch*
*Parody target: online account recovery that asks users to remember details they never chose*
*By: IMI Sketch Desk*
*Batch: IMI-M2-SKETCHES-010*

Cast: Support agent Odo, a baboon; user Pava, a gibbon; security voice Tavi, a parrot; technician Nara, a macaque.

INT. SUPPORT DESK - DAY

Pava calls to reset her password.

ODO: What was your first pet's favorite leaf?

PAVA: I had a pet rock.

TAVI: Security answer incorrect.

PAVA: I made up that question years ago.

Nara checks the system. The password can be reset only after three security questions. The next asks for the name of Pava's first tree. She says "the big one by the path." Tavi rejects it.

NARA: The system requires an exact answer.

PAVA: It never told me the answer had to be exact.

Odo asks if she remembers the month she created the account. Pava says it was during the rainy season. Tavi asks for the precise date. Pava asks whether the system remembers the password.

The system sends a reset link to the email address on file. Pava says she cannot access that email because it is on the locked account. Odo suggests calling the email provider. Nara says the provider will ask for the same security questions.

Pava tries the backup code she wrote down. It is in a notebook inside a drawer. The drawer is locked with a combination she forgot. She asks if the combination is saved in the account. Tavi says yes, but she needs to log in to see it.

Nara opens the drawer with a key. The notebook contains the backup code. Pava reads it aloud, but Tavi says it expired last year. Odo offers to set a new password. Tavi says first Pava must verify that she is human.

PAVA: I am a gibbon.

TAVI: Please select every image containing a gibbon.

The screen shows several pictures of trees. Nara taps them all.

Nara helps Pava search for the original security answers. They find an old note that says "pet: rock; tree: large; date: wet month." Tavi accepts the pet answer only if Pava identifies the rock's favorite mineral. Pava says she never asked. Odo offers to verify her identity by calling her from the office phone. Tavi says the voice must match the account's original voice sample. Pava says she has never recorded one. Nara asks the system to send a paper recovery code to the home address. Tavi says that takes three business days. Pava asks if the password can wait. Odo says the account is not locked for being late; it is locked because the recovery process has no recovery. Nara manually resets it after checking Pava's ID card.

Pava sets a reminder to update her recovery email.

TAG

Pava writes the new password on a card.

ODO: That is not secure.

PAVA: It is secure in the drawer.
