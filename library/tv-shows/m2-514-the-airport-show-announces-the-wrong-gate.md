# The Airport Show Announces the Wrong Gate

*Format: TV show parody*
*Parody target: live airport travel segments that broadcast gate changes after the passengers have moved*
*By: IMI Television Monkey Desk*
*Batch: IMI-M2-TV-018*

Cast: host Rali, a macaque; reporter Toma, a gibbon; gate agent Neri, a lemur; producer Omi, an orangutan; camera assistant Vela, a capuchin.

COLD OPEN

INT. AIRPORT SET - MORNING

Rali points to a screen reading GATE 8. Behind her, the gate agent holds a sign reading GATE 18.

RALI: Boarding is now at gate eight.

NERI: It changed ten minutes ago.

ACT ONE

INT. TERMINAL - CONTINUOUS

Omi says the broadcast feed is delayed. Toma reports from gate 18, where passengers are boarding. The screen behind Rali still shows gate 8. Vela changes the graphic. The number changes to 81. Rali announces the new gate before checking it.

RALI: Gate eighty-one.

TOMA: There are only twenty gates.

Neri checks the departure board. The flight is at gate 18, but a second flight has moved to gate 8. Omi asks for the airline and destination. Rali reads the wrong line. The camera follows a group walking toward gate 8. They are going to a coffee stand.

ACT TWO

INT. TERMINAL - LATER

Toma stands between gates 8 and 18. Neri tells him to hold the flight card in frame. Omi asks the control room to display the same card. The delay causes the screen to show the previous flight. Rali reads its destination. Toma waves both arms to stop her, but the camera cuts to Neri.

[At gate 18, the boarding agent closes the stanchion. A passenger returns, carrying a cup, and asks whether boarding is finished. Neri checks the scanner; the flight is still boarding. She reopens the line.]

Vela tries to update the graphic from the departure board. The board rotates through advertisements between flights. The screen shows a luggage sale instead of a gate number. Omi asks the host to wait for the next update. Rali fills the silence by describing the terminal's moving walkway. It stops behind her. The camera keeps rolling as she steps forward and the floor remains still.

INT. CONTROL ROOM - MOMENTS LATER

Toma checks with the gate agent by phone. Neri confirms that the flight is at gate 18 and has five minutes left to board. Omi removes the animated arrow from the screen. Vela adds the airline code and destination to the card. Rali reads all three details before speaking the gate number. The control room repeats the information back.

INT. TERMINAL - MOMENTS LATER

A gate announcement plays over the loudspeaker. Rali waits for it to finish before giving the new update. Neri reads the board, then checks the gate sign. The two agree. Toma remains beside the actual departure screen; Vela includes the flight number in the frame. Omi asks the control room to freeze the correct graphic rather than animate a route arrow. Rali reads the destination, airline and gate in one breath. A passenger nods and walks toward the right corridor. The camera follows only after Neri confirms the route. Another update appears, this time for a different flight; Vela clears the old card before typing the new gate. Rali asks the gate agent to confirm the second flight. Neri reads its destination from the board, and Toma checks the corresponding sign in the terminal. The crew holds the shot until the two match. Omi does not start the animation. Rali thanks the agent for the update.

ACT THREE

INT. TERMINAL - AFTERNOON

The broadcast uses a still graphic: airline, destination and gate 18. Toma remains beside the actual sign. Neri scans the last passenger. The line clears. Rali reports that boarding has closed. Omi tells her the screen still says OPEN. Vela updates it to CLOSED only after Neri confirms.

A second flight changes gates. The screen flashes an alert. Rali waits. Toma calls Neri, who checks the departure board and confirms gate 8. Omi reads the flight number. Vela changes the graphic. The new card appears without an arrow. Rali announces the change once. The passengers follow the airport's own signs, not the studio animation.

Neri hands Toma the old gate card. He lays it face down. The camera operator captures the correct sign above them. Omi asks for a final line about smooth travel. Rali says to check the current airport board. She does not mention the coffee stand.

TAG

INT. AIRPORT SET - EVENING

Vela labels the graphic template INCLUDE AIRLINE AND DESTINATION. Omi delays the next bulletin until the gate agent confirms. Rali waits at the desk.

FINAL IMAGE: The screen displays gate 18 beside the matching terminal sign, with the old gate card turned face down.
