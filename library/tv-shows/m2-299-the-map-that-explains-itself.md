# The Map That Explains Itself

*Format: TV show parody*
*Parody target: interactive educational television, where a classroom map keeps requiring the host to move props before it will make sense*
*By: IMI Television Monkey Desk*
*Batch: IMI-M2-TV-010*

Premise: Teacher Seli introduces a map of the village, but students keep moving the landmarks and confusing the compass.

Cast: Teacher Seli, capuchin; student Odo, baboon; student Nara, macaque; student Piri, gibbon; camera operator Tavi, lemur.

## Episode: "North Is Over There"

### Cold Open

[CLASSROOM MAP. A SMALL TREE MODEL COVERS THE LEGEND.]

SELI: This map shows the path to the library.

ODO: The tree is on top of the key.

NARA: The map is upside down.

[CUT TO TITLE.]

### Act One

[SELI STANDS BESIDE THE MAP.]

Seli says the map uses a compass rose to show north, south, east, and west. Odo rotates the map so the tree model is easier to see.

SELI: North is at the top.

ODO: The top is now south.

Piri asks if north moved. Nara says the map moved.

Tavi moves the camera to show the compass rose. The tree model blocks it again. Seli asks Odo to lift the model; he carries it across the room and places it on the compass rose.

ODO: The tree is now north.

NARA: The tree is in the classroom.

### Act Two

[THE STUDENTS TRACE A ROUTE.]

Piri uses a string to trace the path to the library. The string crosses the river and passes through a closed gate. Seli says the route should go around the gate.

ODO: That makes it longer.

NARA: It makes it possible.

Odo moves the library marker closer to the school. Tavi says the map is to scale and should not be changed.

PIRI: We can move the marker on the table, not the map.

They set the model pieces on the map. Odo places the school on the river. Nara shifts it back to its marked position.

SELI: The map shows where places are.

ODO: I wanted a shorter route.

NARA: We can choose a different route.

[THE CLASS TESTS THE ROUTE ON THE FLOOR.]

Seli lays a path of paper strips across the room. Odo moves the tree model to mark the first turn. Piri follows the path but reaches the wall.

PIRI: The route ends here.

NARA: The map says the path continues around the garden.

Seli adds another strip around a table. Odo says the table is not on the map. Tavi points out that it represents the garden hedge.

ODO: The hedge has changed shape.

NARA: The table moved.

Piri asks whether the route can go through the classroom door. Seli says the map stops at the library entrance. The students add an arrow showing which side of the library has the main door.

Odo walks the route while holding the map. He turns it at each corner, making north point in a different direction every time.

TAVI: Keep the map facing one way.

ODO: I want the path to stay ahead of me.

NARA: You can rotate yourself instead.

Odo tries that and follows the route correctly. Piri reaches the library model and places the book symbol beside it.

SELI: We have arrived.

ODO: The path was longer than I thought.

NARA: It was the same path.

### Act Three

[THE CLASS BUILDS A LEGEND.]

Seli asks each student to choose a symbol. Odo selects a tree icon, Nara selects a gate, Piri selects a book for the library. They draw the symbols beside the map.

Tavi asks which path is safest. Nara chooses the wider road. Odo chooses the shortcut, but it crosses the river. Piri points to the bridge symbol.

PIRI: The bridge makes the shortcut possible.

SELI: It is still the longer route because of the gate.

ODO: We can open the gate.

NARA: The map does not show a key.

They add a key symbol at the school. Odo moves the tree model off the legend.

[THE CLASS RETURNS THE MODEL PIECES.]

Tavi collects the tree, key, and book symbols. Odo puts the key beside the river by mistake.

ODO: The key belongs at the school.

NARA: It opens the gate.

PIRI: The gate is by the garden.

Seli draws a line from the school to the gate, then to the bridge and library.

SELI: The route is clear.

ODO: The map explains itself.

TAVI: We explained it.

### Tag

[THE MAP IS CLEARLY VISIBLE.]

Seli asks the class to point north. Everyone points in a different direction. They look at the compass rose and correct themselves.

ODO: North is where the map says.

NARA: And where the compass points.

PIRI: The tree is not a compass.

[SFX: CLASS LAUGHS, PAPER MAP ROLLS.]
