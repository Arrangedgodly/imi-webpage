# Chat Says Try It Blindfolded

*Format: TV show parody*
*Parody target: live-streaming shows that let viewer comments steer demonstrations even when the requests are unsafe or unrelated*
*By: IMI Television Monkey Desk*
*Batch: IMI-M2-TV-005*

Premise: Stream host Kavi wants to teach a simple square knot. Moderator Nera needs to keep the live chat useful, while producer Puck keeps highlighting the loudest requests for a more spectacular trick.

Cast: Kavi, a macaque host; Nera, a gorilla moderator; Puck, a capuchin producer; and Lemi, a lemur studio assistant.

## Episode: "The Knot Is the Point"

### Cold Open

[SMALL STUDIO. KAVI HOLDS TWO ROPES. THE LIVE CHAT SCROLLS ON A MONITOR.]

KAVI: Today we are learning a square knot.

[PUCK HIGHLIGHTS A COMMENT: "DO IT BLINDFOLDED."]

KAVI: We will keep our eyes open.

NERA: Good.

[ANOTHER COMMENT APPEARS: "USE THE THICKEST ROPE."]

LEMI: That rope is tied to the light stand.

[PUCK SETS IT DOWN.]

KAVI: We will use the short rope on the table.

NERA: The camera can show both ends.

[PUCK TURNS THE CAMERA TOWARD THE CHAT WINDOW. THE ROPE DISAPPEARS FROM FRAME.]

LEMI: The lesson is offscreen.

[PUCK REFRAMES THE TABLE AND LOCKS THE CAMERA.]

### Act One

[KAVI LAYS TWO SHORT ROPES ON A TABLE.]

KAVI: Right over left, then left over right.

[HE TIES THE KNOT SLOWLY. NERA CHECKS IT.]

NERA: That is secure for the demonstration.

[THE CHAT FLOODS WITH "FASTER" AND "ONE HAND."]

KAVI: First, check which end crosses over.

NERA: That is the part people confuse.

[PUCK STARTS A SPEED GRAPHIC. IT DISPLAYS A RECORD TIME FROM ANOTHER SHOW.] 

KAVI: We are not racing.

[PUCK REMOVES THE GRAPHIC AND SHOWS A SIMPLE CLOSE-UP OF THE TWO ENDS.]

PUCK: Viewers want a challenge.

KAVI: The goal is to learn the knot.

[PUCK HANDS HIM A GLOVE. KAVI PUTS IT ON. THE KNOT SLIPS.]

KAVI: The glove changes my grip.

NERA: The demonstration is not improved.

[LEMI REMOVES THE GLOVE AND SETS THE ROPES STRAIGHT.]

### Act Two

[THE CHAT ASKS KAVI TO TIE A KNOT AROUND A PERSON'S WRIST.]

NERA: We will not do that.

PUCK: It is the most-requested comment.

KAVI: We can tie it around a rolled towel.

[HE ROLLS A TOWEL AND SECURES IT GENTLY. NERA CHECKS THAT IT CAN BE LOOSENED.]

NERA: We can show how to undo it, too.

[PUCK ADDS A POLL: "KEEP THE KNOT OR UNDO IT?"]

KAVI: We need both steps.

[THE CHAT VOTES FOR A TIMER. PUCK ADDS A COUNTDOWN GRAPHIC. KAVI STARTS THE DEMONSTRATION AGAIN, BUT THE CHAT OBSCURES THE ROPE WITH EMOJIS.]

LEMI: I cannot see the knot.

NERA: Move the comments.

[PUCK SHRINKS THE CHAT WINDOW. KAVI SHOWS THE TWO LOOPS CLEARLY.]

KAVI: Pull both ends evenly. Now test the knot on the towel before using it.

[THE KNOT HOLDS. LEMI PULLS IT APART BY FOLLOWING THE RELEASE STEPS.]

[A VIEWER ASKS IF A SQUARE KNOT CAN BE TIED IN A DARK ROOM.]

KAVI: It is easier to see the two ends in good light.

PUCK: We could turn off the studio lamps for the challenge.

NERA: We are not turning off the lights.

[PUCK CLOSES THE POLL. THE VIEWER'S QUESTION REMAINS ON SCREEN.]

[PUCK CLEARS THE TABLE. KAVI CHECKS THAT BOTH PRACTICE ROPES ARE SHORT AND FREE OF DAMAGE.]

NERA: Any last questions before we end?

KAVI: We can practice the knot again next time.

[THE STREAM ENDS WITH THE DEMONSTRATION TABLE IN VIEW, NOT THE CHAT WINDOW.]

### Act Three

[PUCK READS THE CHAT. A VIEWER ASKS IF THE KNOT CAN SUPPORT A SWING.]

KAVI: Not from this demonstration.

NERA: We have not tested a swing, a load, or outdoor conditions.

PUCK: The chat wants a rating.

KAVI: The knot holds the towel. That is what we tested.

[NERA TYPES A MODERATOR NOTE: "DO NOT USE THIS DEMONSTRATION FOR CLIMBING OR LOAD-BEARING." THE CHAT SLOWS.]

LEMI: The explanation is still visible.

[KAVI REPEATS THE KNOT ON THE SHORT ROPES, THEN SHOWS HOW TO UNTIE IT.]

KAVI: Right over left, left over right. To release, loosen the crossing and pull the end through.

[PUCK LETS THE STREAM END WITHOUT A FINAL STUNT.]

PUCK: We have thirty seconds left.

KAVI: Then we can answer questions about the steps.

[NERA READS A QUESTION ABOUT WHICH ROPE CROSSES FIRST. KAVI DEMONSTRATES SLOWLY.]

LEMI: That is the same lesson.

KAVI: It is a useful question.

[KAVI CHECKS THE ROPES FOR FRAYED ENDS. NERA PUTS THE PRACTICE ROPE IN THE DRAWER.]

PUCK: Next time, do we follow the chat?

KAVI: We can read it. We still teach what we planned.

[THE NEXT STREAM CARD SHOWS THE TIME AND THE TOPIC, NOT A VIEWER COUNT. NERA SETS THE PRACTICE ROPES BESIDE THE LESSON NOTES.]

### Tag

[THE CHAT ASKS FOR A TRICK SHOT. KAVI TIES THE ROPES INTO A BOW AND PUTS THEM AWAY.]

KAVI: Tomorrow we will practice the same knot again.

NERA: With the chat open?

KAVI: With the rope visible.
